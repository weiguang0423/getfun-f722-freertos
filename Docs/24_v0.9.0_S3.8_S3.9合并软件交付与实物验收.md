## 5. S3.9 ADC原始链路验收

### 5.1 无电池/USB供电

- [ ] UART4持续输出 `power adc=1`，`seq`与 `starts`约每秒增加50。
- [ ] `dma_err=0`、`overrun=0`；`busy`和`recovery`不持续增加。
- [ ] PC0～PC3原始值均在0～4095，悬空的PC2/PC3只记录、不解释为有效传感器。
- [ ] 无电池时 `present=0`、`cells=0`，App不显示虚假电池电压。

### 5.2 电池插入与拔出

- [ ] 接入限流电源或已知安全电池后约200 ms确认 `present=1`。
- [ ] 自动电芯数与实际1～8S一致，低压变化期间不会跳成较少电芯。
- [ ] 拔出后约200 ms变为 `present=0`，mAh在确认拔出时清零。
- [ ] 强制ADC停更或制造DMA故障后100 ms内 `adc_running=0`并设置bit 7；恢复计数可解释。

## 8. 低压状态与App Power显示

使用限流可调电源缓慢改变电压，不使用已深度放电的锂电池制造临界条件。

- [ ] App能读取Battery State、电压表和电流表，页面不因缺少MSP响应中断。
- [ ] 每电芯高于3.50 V稳定1 s后为OK。
- [ ] 每电芯低于或等于3.50 V稳定1 s后为WARNING。
- [ ] 每电芯低于或等于3.30 V稳定1 s后为CRITICAL，并设置内部bit 7。
- [ ] 短于1 s的瞬时跌落不改变状态。
- [ ] 回升需跨过每电芯0.10 V迟滞并稳定1 s，不在阈值附近抖动。
- [ ] 本阶段只验证状态和抑制快照，不宣称已经实现飞行中低压降落或真实电机停机。
