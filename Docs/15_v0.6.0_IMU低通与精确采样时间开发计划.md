# v0.6.0 IMU低通与精确采样时间开发计划

> 上一基线：`v0.5.0-accel-calibration-params-baseline`（`f2ebed3`）<br>
> 目标标签：`v0.6.0-imu-filter-timing-baseline`<br>
> 当前状态：✅ 真实硬件验收通过，准备冻结基线<br>
> 目标硬件：STM32F722RET6，216 MHz Cortex-M7，ICM42688P 1 kHz

## 1. 目标与数据语义

本阶段为后续Mahony建立可信的时间和输入边界：

```text
ICM42688P DMA完成
  → ISR捕获DWT周期计数
  → 任务侧扩展为uint32微秒时间戳
  → 计算并校验真实dt
  → SI换算 + CW90
  → 陀螺/加速度校准
  ├─ 校准后未滤波数据 → MSP_RAW_IMU / 校准状态机 / 原始诊断
  └─ 校准后数据 + 有效dt → Gyro/Accel PT1
       → filtered_* → 后续Mahony
```

`MSP_RAW_IMU` 继续发布校准后、未滤波的机体系数据，避免改变v0.2～v0.5已经验收的
方向和缩放语义。新增长度固定的GETFUN MSP2诊断和UART摘要观察时间及滤波状态。

## 2. 微秒时间源

### 2.1 选择结论

使用Cortex-M7 DWT `CYCCNT`，不复用TIM6或FreeRTOS tick：

| 候选 | 分辨率 | 冲突/限制 | 结论 |
|---|---:|---|---|
| FreeRTOS tick | 1 ms | 无法测量1 kHz样本内抖动 | 不使用 |
| TIM6 CNT + HAL tick | 1 µs | TIM6已作为HAL时基；组合读取和Flash停顿语义复杂 | 不修改CubeMX时基 |
| DWT CYCCNT | 1/216 MHz | 32位原始计数约19.88秒回绕，需要软件扩展 | 采用 |

DWT只提供计数寄存器，不占用Timer、DMA、GPIO或中断。初始化时检查：

- `SystemCoreClock` 不低于1 MHz且可整除1 MHz。
- DWT存在周期计数器。
- 解锁DWT、打开 `CoreDebug.DEMCR.TRCENA` 和 `DWT.CTRL.CYCCNTENA`。

### 2.2 取时与回绕

DMA完成ISR只读取一次 `DWT->CYCCNT` 并通知ImuTask，不做除法、浮点或状态发布。
ImuTask使用无符号减法扩展相邻周期计数，并保留不足1 µs的余数：

```text
delta_cycles = current_cycles - previous_cycles
total_cycles = delta_cycles + fractional_cycles
timestamp_us += total_cycles / cycles_per_us
fractional_cycles = total_cycles % cycles_per_us
```

在线时每个DMA样本更新；离线或DRDY未就绪时至少每1秒维护一次，严格短于216 MHz下
约19.88秒的原始回绕周期。对外 `uint32_t timestamp_us` 约71.58分钟回绕，所有间隔
必须使用无符号减法，不能直接比较绝对时间戳大小。

调试器长时间暂停可能破坏“至少每19.88秒维护一次”的前提；带断点运行不作为长期
时间验收证据。

## 3. `dt`规则

| 项目 | 固定值/规则 |
|---|---|
| 标称采样间隔 | 1000 µs |
| 最小有效间隔 | 500 µs |
| 最大有效间隔 | 2000 µs |
| 首个样本 | 有时间戳，无有效dt，不进入后续姿态 |
| 初始化/恢复 | 清除上一样本时间并重置滤波 |
| 超界/时间源失败 | 当前 `timing_valid=0`，增加异常计数并重置滤波 |
| min/max统计 | 只统计有效dt |

Flash保存、DMA超时、传感器恢复或丢样造成的长间隔不能夹紧成正常值。异常样本仍可
用于当前诊断，但不得被未来Mahony积分；后续首个正常间隔重新建立滤波READY。

## 4. 低通设计

### 4.1 首版算法

使用每轴一阶PT1，不引入大型DSP库：

```text
omega = 2 * pi * cutoff_hz
alpha = (omega * dt) / (1 + omega * dt)
y[n] = y[n-1] + alpha * (x[n] - y[n-1])
```

| 数据 | 截止频率 | 目的 |
|---|---:|---|
| Gyro | 100 Hz | 抑制高频噪声，同时保留后续Rate/姿态带宽 |
| Accel | 30 Hz | 为重力方向估计提供更平滑输入 |

PT1按真实 `dt` 计算alpha，能够直接覆盖当前1 kHz轻微抖动；比首版动态重算Biquad
系数更小、更易验证。Notch、动态滤波和RPM Filter不在本阶段。

### 4.2 初始化与故障

- 第一个有限样本只播种滤波状态，`filter_ready=0`。
- 第二个具有有效dt的样本完成首次更新后，`filter_ready=1`。
- 任一输入、dt或计算结果非有限，或dt越界，立即用当前有限输入重新播种并保持
  `filter_ready=0`。
- 传感器初始化、故障恢复和参数Flash造成的异常间隔必须清除历史滤波状态。
- 算法模块不依赖HAL、RTOS、日志或全局状态，不使用动态内存。

## 5. 状态与诊断接口

`app_imu_sample_t` 新增：

- `timing_source_ready`、`timing_valid`、`filter_ready`
- `sample_timestamp_us`、`sample_interval_us`
- `sample_interval_min_us`、`sample_interval_max_us`
- `timing_invalid_count`、`timing_reset_count`、`filter_reset_count`
- `filtered_acceleration_m_s2[3]`
- `filtered_angular_rate_rad_s[3]`

新增解锁抑制位：

```text
APP_ARMING_INHIBIT_IMU_TIMING_INVALID = 0x00000010
```

只有IMU在线、当前dt有效且滤波READY时清除。当前版本仍没有真实ARM/DShot输出。

新增GETFUN MSP2 `0x4001`，固定40字节、小端：

| 偏移 | 字段 | 大小 |
|---:|---|---:|
| 0 | payload version，固定1 | 1 |
| 1 | flags：bit0 time source，bit1 timing，bit2 filter | 1 |
| 2 | reserved | 2 |
| 4 | sample_timestamp_us | 4 |
| 8 | sample_interval_us | 4 |
| 12 | sample_interval_min_us | 4 |
| 16 | sample_interval_max_us | 4 |
| 20 | timing_invalid_count | 4 |
| 24 | timing_reset_count | 4 |
| 28 | filter_reset_count | 4 |
| 32 | gyro cutoff，mHz | 4 |
| 36 | accel cutoff，mHz | 4 |

标准 `MSP_STATUS.cycleTime` 在当前dt有效时更新为实际微秒间隔；标准
`MSP_RAW_IMU` 仍使用校准后未滤波数据。

## 7. 本阶段不包含

- Mahony四元数姿态和Betaflight三维模型。
- Biquad、Notch、动态滤波、RPM Filter和频谱自适应。
- 运行时滤波参数写入、完整CLI和Betaflight参数组。
- ICM42688P GPIO DRDY/EXTI；当前仍使用寄存器DRDY门控。
- CRSF、PID、Mixer、DShot或任何有效电机输出。
