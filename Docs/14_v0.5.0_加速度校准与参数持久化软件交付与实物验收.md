# v0.5.0 加速度校准与参数持久化软件交付及实物验收

> 上一基线：`v0.4.0-gyro-calibration-baseline`（`758d424`）<br>
> 目标标签：`v0.5.0-accel-calibration-params-baseline`<br>
> 软件完成日期：2026-07-30<br>
> 当前状态：✅ 真实硬件验收通过，冻结为v0.5.0基线

## 1. 软件交付结论

本轮已经把STM32F722内部Flash划分为256 KB程序区和两个128 KB参数槽，建立带
magic、版本、长度、序号、CRC32和最后提交标记的v1参数记录。保存时只擦除非活动槽，
因此擦除、写入或掉电中断不会先破坏旧记录。

在v0.4.0的机体系IMU链路中新增水平单面加速度校准：

```text
MSP_ACC_CALIBRATION
  → ImuTask排队请求
  → 250个水平静止预热样本
  → 2000个Welford统计样本
  → 运动、非水平、方差和偏置复核
  → 写入非活动参数槽
  → 读回及CRC/提交验证
  → 切换当前加速度偏置
```

算法候选值只有在Flash提交成功后才成为有效偏置。没有校准、参数损坏或保存失败都会
保持独立解锁抑制；当前版本仍没有真实ARM/DShot输出。

## 2. Flash与记录交付

### 2.1 链接边界

| 区域 | 起止地址 | 链接器大小 |
|---|---|---:|
| 程序FLASH | `0x08000000`～`0x0803FFFF` | 256 KB |
| PARAM_A / Sector 6 | `0x08040000`～`0x0805FFFF` | 128 KB |
| PARAM_B / Sector 7 | `0x08060000`～`0x0807FFFF` | 128 KB |

Debug map已确认：

```text
FLASH    origin=0x08000000 length=0x00040000
PARAM_A  origin=0x08040000 length=0x00020000
PARAM_B  origin=0x08060000 length=0x00020000

__parameter_slot_a_start__ = 0x08040000
__parameter_slot_a_end__   = 0x08060000
__parameter_slot_b_start__ = 0x08060000
__parameter_slot_b_end__   = 0x08080000
```

Debug映像长度80,984字节，Release映像长度45,128字节，均小于参数区起点相对偏移
`0x40000`。链接器在程序超过256 KB时会直接失败。

### 2.2 v1记录

记录固定48字节：

```text
magic/version/length/sequence/flags
accel_bias_m_s2[3]
reserved[3]
crc32
commit
```

- magic：`0x47465052`
- version：`1`
- length：`48`
- flags bit0：加速度校准有效
- CRC32：IEEE CRC-32，覆盖前40字节
- commit：`0x434F4D54`，最后单独写入
- 偏置：有限值且单轴不超过0.2 g

### 2.3 启动选择与保存

- 两槽空白：加载安全默认值，参数存储状态有效，但加速度未校准。
- 一槽有效：加载该槽。
- 一槽有效、另一槽损坏：加载有效槽并报告恢复状态。
- 两槽有效：使用支持32位回绕比较的较新sequence。
- 无有效槽且存在非空损坏：加载默认值并设置参数损坏抑制。
- 保存失败：不切换RAM参数，旧活动槽保持有效。

## 3. 加速度校准交付

### 3.1 算法与状态

新增纯算法模块：

```text
APP/Inc/algorithms/accel_calibration.h
APP/Src/algorithms/accel_calibration.c
```

固定状态值：

| 值 | 状态 | 含义 |
|---:|---|---|
| 0 | `NOT_CALIBRATED` | 没有已提交偏置 |
| 1 | `READY` | 正在应用已提交偏置 |
| 2 | `CALIBRATING` | 正在累计窗口 |
| 3 | `CANDIDATE_READY` | 算法完成，等待Flash提交 |
| 4 | `SAVE_FAILED` | Flash保存失败 |

固定门限：

- 250个连续预热样本和2000个统计样本。
- 单轴角速度不超过5 deg/s。
- 加速度模长0.8 g～1.2 g。
- 瞬时水平分量不超过0.12 g。
- 最终水平均值不超过0.08 g。
- 最终Z绝对值0.9 g～1.1 g。
- 单轴标准差不超过0.03 g。
- 候选偏置单轴不超过0.2 g。

目标Z使用均值符号选择 `+g` 或 `-g`，正放和反放的水平单面都计算相同传感器偏置；
明显倾斜仍会被水平门限拒绝。

### 3.2 ImuTask顺序

```text
SI + CW90
  → gyro_calibration_process/apply
  → accel_calibration_process（未扣加速度偏置）
  → 参数提交
  → accel_calibration_apply
  → app_state
```

- 旧偏置在重新校准期间仍可用于显示，但校准状态不是READY，因此不允许未来ARM。
- IMU离线会取消进行中的校准，并恢复当前已提交偏置。
- 参数Flash只由ImuTask在DMA事务结束后写入。
- 写Flash前再次强制Motor 1～8为GPIO低电平。

## 4. MSP、状态与解锁抑制

### 4.1 Betaflight App触发

实现标准命令：

```text
MSP_ACC_CALIBRATION = 205
```

请求必须为空负载，并满足：

- IMU在线。
- 陀螺校准READY。
- 当前没有加速度校准或待提交候选。
- ImuTask没有尚未消费的重复请求。

因此可以从Betaflight Configurator的加速度校准入口触发，不需要引入完整CLI。

### 4.2 GETFUN MSP2诊断

自定义命令 `0x4000` 返回56字节、小端：

| 偏移 | 字段 | 大小 |
|---:|---|---:|
| 0 | payload version（1） | 1 |
| 1 | storage_valid | 1 |
| 2 | load_result | 1 |
| 3 | last_save_result | 1 |
| 4 | active_slot | 1 |
| 5 | invalid_slot_mask | 1 |
| 6 | accel_calibration_state | 1 |
| 7 | reserved | 1 |
| 8 | sequence | 4 |
| 12 | save_error_count | 4 |
| 16 | last_hal_error | 4 |
| 20 | arming_inhibit_flags | 4 |
| 24 | calibration_sample_count | 2 |
| 26 | reserved | 2 |
| 28 | restart/motion/level/invalid计数 | 16 |
| 44 | bias_mm_s2 X/Y/Z | 12 |

UART 1 Hz输出同样的信息。

### 4.3 新增抑制位

| 标志 | 值 | 条件 |
|---|---:|---|
| `APP_ARMING_INHIBIT_ACCEL_NOT_CALIBRATED` | `0x00000004` | 加速度状态不是READY |
| `APP_ARMING_INHIBIT_PARAMETERS_INVALID` | `0x00000008` | 没有可恢复参数记录且参数区损坏 |

空白Flash使用安全默认值，不设置“参数损坏”位，但仍设置“加速度未校准”位。

## 6. 实物验收步骤

验收前必须拆除螺旋桨并断开Motor动力电源。首次烧录v0.5.0时，烧录工具不得执行
整片Mass Erase以外的意外参数覆盖；测试参数清空时应明确擦除Sector 6和7。

### 6.1 空白参数区与首次校准

1. 擦除Sector 6和7，烧录Debug固件。
2. 上电静止，等待陀螺校准READY。
3. 观察UART或MSP2 `0x4000`。
4. 在Betaflight Configurator执行加速度计校准并保持水平静止至少5秒。

- [x] 启动时 `params valid=1 load=0 slot=0 seq=0`。
- [x] 加速度状态为0，抑制位 `0x00000004`保持置位。
- [x] App校准命令被接受，状态进入2。
- [x] 进度连续增长至2000。
- [x] 状态短暂经过3并在保存成功后进入1。
- [x] `save=1 slot=1 seq=1`。
- [x] 三轴偏置有限且绝对值均不超过1.96133 m/s²。
- [x] 加速度未校准抑制位清除。
- [x] Flash写入后IMU采样、USB和UART自动恢复。

记录：

```text
校准放置方向：
完成时间：
bias_mm_s2 X/Y/Z：
Flash保存停顿时间：
保存前后missed/dma错误：
```

### 6.2 运动和非水平拒绝

- [x] 校准期间持续转动时不会进入状态3，`motion`增加。
- [x] 已有进度后运动，进度清零且`restart`增加。
- [x] 倾斜超过门限时不会进入状态3，`level`增加。
- [x] 停止动作并重新水平放置后，无需重启即可完成。
- [x] 移动/倾斜期间没有HardFault、USB失联或有效Motor脉冲。

### 6.3 重启保持与A/B轮换

1. 完成首次校准并记下slot、sequence和偏置。
2. 断电重启。
3. 再执行一次水平校准。
4. 再次断电重启。

- [x] 首次重启加载slot A，sequence=1，加速度状态直接为READY。
- [x] 偏置与保存前一致，不要求重新校准。
- [x] 第二次保存切换slot B，sequence=2。
- [x] 第二次重启选择较新的slot B。
- [x] 多次重复保存时A/B交替，sequence递增。
- [x] 正常重启不会增加save_error或设置参数损坏位。

### 6.4 损坏与掉电恢复

必须通过SWD/烧录工具精确操作Sector 6/7，禁止误擦程序区：

- [x] 只损坏较新槽的commit或CRC后，重启加载旧槽并报告RECOVERED。
- [x] 旧偏置仍可正常应用。
- [x] 两槽都损坏后加载安全默认值，`storage_valid=0`。
- [x] 参数损坏与加速度未校准抑制位同时置位。
- [x] 在损坏状态重新校准可以写出新有效槽并恢复。
- [x] 在擦除、主体写入或commit前断电，重启至少能加载旧槽。
- [x] 任何不完整记录都不会被误判为新参数。

记录：

```text
损坏/断电阶段：
重启load_result：
active_slot/sequence：
invalid_slot_mask：
是否使用旧偏置：
```

### 6.5 校准残差与方向

- [x] 水平静止时X/Y均值接近0，Z绝对值接近9.80665 m/s²。
- [x] 六面放置的主要轴和正负方向与v0.2～v0.4一致。
