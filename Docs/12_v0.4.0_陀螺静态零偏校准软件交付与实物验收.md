# v0.4.0 陀螺静态零偏校准软件交付及实物验收

> 上一基线：`v0.3.0-imu-dma-drdy-baseline`（`67e38ea`）<br>
> 目标标签：`v0.4.0-gyro-calibration-baseline`<br>
> 软件完成日期：2026-07-29<br>
> 实物验收日期：2026-07-30<br>
> 当前状态：开发者已确认验收通过并授权创建目标标签

## 1. 交付结论

本轮已经在v0.3.0的1 kHz DMA采样链上加入陀螺上电静态零偏校准。校准输入是完成
SI换算和 `CW90` 变换后的机体系角速度，因此校准结果可直接供MSP、未来Mahony和PID使用。

最短校准窗口为：

```text
250个连续静止预热样本
  + 2000个连续静止统计样本
  = 1 kHz下理论约2.25秒
```

运动或异常不会超时放行；状态会停留在 `CALIBRATING`，直到得到合格窗口。IMU离线和
校准未完成分别设置独立解锁抑制位。当前项目尚未实现真实ARM状态机，因此本轮交付的是
后续ARM必须消费的安全状态，而不是有效电机控制。

开发者于2026-07-30确认本文件规定的静止启动、运动拒绝、校准残差、重新上电、
故障恢复、v0.3.0回归、30分钟稳定性和Motor安全项目全部通过。

## 2. 已交付的软件内容

### 2.1 纯算法模块

新增：

```text
APP/Inc/algorithms/gyro_calibration.h
APP/Src/algorithms/gyro_calibration.c
```

实现：

- `NOT_STARTED`、`CALIBRATING`、`READY`三态状态机。
- 5 deg/s单轴瞬时角速度门限。
- 0.8 g～1.2 g加速度模长门限。
- 250样本连续静止预热。
- 2000样本Welford在线均值和方差。
- 0.5 deg/s单轴窗口标准差门限。
- 运动、无效样本和窗口重启饱和计数。
- READY后冻结机体系零偏并支持原地数组扣除。
- 无HAL、FreeRTOS、app_state、日志和动态内存依赖。

### 2.2 ImuTask

当前数据流：

```text
ICM42688P DMA
  → 原始14字节解析
  → SI单位
  → CW90机体系
  → gyro_calibration_process()
  → gyro_calibration_apply()
  → app_state_publish_imu()
```

- ImuTask静态持有唯一校准上下文。
- 每次ICM42688P成功初始化后启动新校准。
- CALIBRATING期间继续发布未扣偏角速度，便于观察运动。
- READY转换完成的同一帧开始扣除零偏。
- 单次/短暂DMA错误不清除已经完成的零偏。
- 连续三次错误导致IMU离线时状态回到NOT_STARTED。
- 故障解除并完整初始化后重新校准。

### 2.3 app_state与解锁抑制

IMU快照新增：

- 校准状态。
- 当前稳定样本进度。
- 窗口重启、运动拒绝和无效样本计数。
- 三轴机体系零偏，单位rad/s。

全局状态新增：

| 标志 | 值 | 含义 |
|---|---:|---|
| `APP_ARMING_INHIBIT_IMU_NOT_READY` | `0x00000001` | IMU不在线 |
| `APP_ARMING_INHIBIT_GYRO_NOT_CALIBRATED` | `0x00000002` | 陀螺校准未READY |

`app_state_publish_imu()`原子更新IMU快照和这两个标志。现有
`configurator_arming_disabled`仍保持宿主字段含义，没有被传感器状态复用。

### 2.4 UART与MSP

- 1 Hz UART增加校准状态、进度、重启/拒绝/无效计数、解锁抑制和三轴零偏。
- `MSP_RAW_IMU`缩放公式没有改变。
- CALIBRATING期间MSP显示对齐后的实时角速度。
- READY后MSP显示已经扣除静态零偏的角速度。
- ACC、温度、传感器在线位和DMA诊断逻辑没有改变。

## 4. UART预期输出

启动后IMU初始化成功，但校准尚未完成：

```text
imu present=1 who=0x47 status=0 bus=0 hz=... samples=...
imu cal=1 progress=.../2000 restart=0 motion=0 invalid=0
    inhibit=0x00000002 bias_mrad_s=[0,0,0]
```

静止约2.25秒并通过方差复核后：

```text
imu cal=2 progress=2000/2000 restart=0 motion=0 invalid=0
    inhibit=0x00000000 bias_mrad_s=[...,...,...]
imu acc_mm_s2=[...] gyro_mrad_s=[接近0,接近0,接近0] ...
```

校准期间移动：

```text
imu cal=1 progress重新从0增长
motion持续增加
若移动前已有进度，restart增加
```

状态码：

| `cal` | 含义 |
|---:|---|
| 0 | 未开始；IMU未初始化或已离线 |
| 1 | 正在等待/累计连续静止窗口 |
| 2 | 校准完成，零偏正在应用 |

## 5. 实物验收步骤

验收前拆除螺旋桨并断开Motor动力电源。板卡应放在稳定、无明显振动的水平桌面；
校准本身不要求水平，但水平便于同时回归加速度模长和轴向。

### 5.1 静止启动

1. 烧录Debug固件。
2. 上电后不要触碰板卡至少5秒。
3. 观察UART校准摘要和Betaflight App原始IMU。

- [x] IMU首先进入 `cal=1`。
- [x] `progress`能够连续增长到2000。
- [x] 约2.25～5秒内进入 `cal=2`。
- [x] `bias_mrad_s`三轴为有限、合理且可重复的值。
- [x] `inhibit`在校准完成后清除位0和位1。
- [x] `invalid=0`。
- [x] READY后Betaflight App的ACC和GYRO仍在线。

记录：

```text
上电到cal=2时间：
bias_mrad_s X/Y/Z：
restart：
motion：
invalid：
```

### 5.2 运动拒绝

1. 重新上电。
2. 在最初5秒内持续缓慢转动和倾斜板卡。
3. 停止动作并把板卡稳定放置。

- [x] 移动期间不会进入 `cal=2`。
- [x] `motion`增加。
- [x] 已经形成部分窗口后移动会使 `restart`增加。
- [x] `progress`被清零并重新增长。
- [x] 停止动作后无需重启即可自动进入 `cal=2`。
- [x] 移动过程不导致HardFault、USB断开或DMA错误。

### 5.3 校准残差

校准完成后保持静止10秒，通过UART连续记录或SWD采样计算三轴均值。

- [x] 三轴角速度均值绝对值均不超过0.5 deg/s（约8.73 mrad/s）。
- [x] 数值没有NaN/Inf。
- [x] 静止噪声没有明显跳变或单轴持续漂移。
- [x] 绕X/Y/Z分别旋转时，主要变化轴和符号与v0.3.0一致。
- [x] 回到静止后角速度回到零附近。

记录：

```text
10秒均值 mrad/s X/Y/Z：
峰峰值 mrad/s X/Y/Z：
温度 m°C：
```

### 5.4 重新上电与故障恢复

- [x] 每次重新上电都从 `cal=1` 开始，不直接复用旧零偏。
- [x] 两次静止启动得到的零偏符号和数量级合理一致。
- [x] 可控制造连续三次SPI/DMA失败后，`present=0`、`cal=0`。
- [x] 故障期间IMU和校准解锁抑制位均置位。
- [x] 故障解除后IMU自动初始化并重新进入 `cal=1`。
- [x] 恢复后必须重新达到 `cal=2`，抑制位才清除。
- [x] 故障和恢复全过程USB/UART保持可用。
