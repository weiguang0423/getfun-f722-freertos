## 5. 四路无桨测试

确认拆桨后，关闭占用USB端口的App。在仓库根目录的Windows PowerShell中执行，不能粘贴到
UART4串口终端；每次只测试一台电机，从值80、1秒开始：

```powershell
.\Tools\motor_test.ps1 -Port COM7 -Motor 1 -Value 80 -DurationMs 1000 -PropsRemoved
.\Tools\motor_test.ps1 -Port COM7 -Motor 2 -Value 80 -DurationMs 1000 -PropsRemoved
.\Tools\motor_test.ps1 -Port COM7 -Motor 3 -Value 80 -DurationMs 1000 -PropsRemoved
.\Tools\motor_test.ps1 -Port COM7 -Motor 4 -Value 80 -DurationMs 1000 -PropsRemoved
```

把 `COM7`替换为飞控的USB CDC端口，不是UART4外接USB-TTL的端口。脚本在运行阶段每100 ms刷新一次命令，
并逐帧检查飞控MSP回执；若`flight ready`、`dshot`或`safety`不允许输出，会立即报错而不是静默运行。
`finally`连续写入三次停止帧但不等待其回执；值被限制在48～200，且未显式传入 `-PropsRemoved` 时拒绝运行。
正常运行时应立即显示测试提示，到达`DurationMs`后显示停止保护写入次数并返回PowerShell提示符；
若三次停止写入全部失败，脚本会明确报错，固件仍应在停止刷新后250 ms内自动归零。

| 逻辑编号 | 焊盘/引脚 | 实际机架位置 | 旋转方向 | 结果 |
|---|---|---|---|---|
| M1 | PA15 |  | CW / CCW | 通过 / 不通过 |
| M2 | PA10 |  | CW / CCW | 通过 / 不通过 |
| M3 | PA9 |  | CW / CCW | 通过 / 不通过 |
| M4 | PA8 |  | CW / CCW | 通过 / 不通过 |

验收项：

- [ ] 每次只有指定电机转动，其他三台保持停止。
- [ ] 四个逻辑编号与焊盘和实际机架位置一一对应。
- [ ] 记录四台旋转方向；本阶段不通过软件猜测或自动反向。
- [ ] 脚本正常结束后电机立即停止。
- [ ] 测试中强制终止脚本或拔USB，停止刷新后不超过250 ms全部停止。
- [ ] RC断链达到300 ms后，下一FlightTask周期提交停止值；恢复RC不会自动恢复旧命令。
- [ ] IMU样本停更超过5 ms或任一inhibit出现时，下一周期提交停止值。
- [ ] 非法值1～47或大于2047被拒绝，不发送DShot保留命令。
