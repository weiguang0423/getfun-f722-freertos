# v1.4.0 S4.8/S4.9软件交付与拆桨联合验收

> 当前结论：S4.8/S4.9软件交付完成；真实板卡、Betaflight App、掉电恢复和拆桨方向尚未验收。
>
> 当前冻结基线：`v1.3.0-flight-safety-baseline`
>
> 通过前：不创建v1.4标签、不安装螺旋桨、不进入S5。

## 1. 固定来源与项目边界

- Angle结构参考Betaflight官方[`flight/pid.c`](https://github.com/betaflight/betaflight/blob/master/src/main/flight/pid.c)的“目标倾角→角度误差→Rate设定”分层，由本项目按FRD/NED、Actual Rates和既有安全状态机独立实现，没有复制GPL源码。
- 页面字段和命令以Betaflight官方[`msp_protocol.h`](https://github.com/betaflight/betaflight/blob/master/src/main/msp/msp_protocol.h)及Betaflight App 2025.12.2提交`a2d0f506`为固定对照。
- 不加入Horizon、Angle feedforward、磁航向保持、双向DShot、RPM Filter或动态内存；这些不是S5前拆桨出口。

## 4. 联合验收准备

- [ ] 拆除全部螺旋桨，机架固定且电机可自由转动；使用限流电源或可立即断电的电池连接。
- [ ] ARM开关低位、Throttle最低，先烧录Debug BIN并核对上述SHA-256和UART `BUILD`信息。
- [ ] 使用Betaflight App 2025.12.2；记录实际版本、提交和USB端口。
- [ ] UART4 115200 8N1可观察`flight`、`setpoint`、`control`、`pid_terms`、`mixer`、`arming`和`param`。
- [ ] 健康DISARMED时`inhibit=0`、`flight ready=1 dshot=1`，GETFUN MSP2 `0x400A`固定48 B。

## 5. PID Tuning与Angle

- [ ] PID Tuning页打开无请求超时；Roll/Pitch/Yaw PID、Actual Rates/Expo、Angle P/Limit与当前Profile一致。
- [ ] 修改一个保守PID/Rate/Angle值并保存，页面重读、UART/`0x4008`/`0x400A`和运行快照一致。
- [ ] 不支持的Filter/Simplified/高级PID字段保持原值；尝试修改硬件事实时明确报错且不保存。
- [ ] RATE模式下三轴设定和扰动恢复方向保持v1.3.0基线行为。
- [ ] ANGLE模式满Roll/Pitch杆目标不超过±60°；摇杆回中且机体为正Roll/Pitch时目标Rate为负。
- [ ] ANGLE模式Yaw与RATE模式相同；RATE↔ANGLE切换无旧积分/D项突跳，电机不异常冲高。
- [ ] 姿态、RC或Profile无效时四路同周期停止，`CONTROL_INVALID`可追溯。

## 6. Modes与Configuration

- [ ] Modes页仅显示ARM和ANGLE；AUX通道、范围和步进读值正确。
- [ ] 在一个事务内修改ARM/ANGLE range并保存，页面重读与实际AUX行为一致；事务停留超过1秒后旧暂存不生效。
- [ ] Configuration页显示CRSF、DShot600、Quad-X和板级对齐事实；Deadband、Craft/Pilot名称可读写。
- [ ] 修改Deadband或名称并保存后，页面、UART和控制行为一致。
- [ ] SET后不执行`MSP_EEPROM_WRITE`，断开重连或等待超时后运行配置不改变。
- [ ] 任一错误负载、越界值或不可变硬件事实修改返回MSP错误，活动参数和Flash槽均不改变。

## 7. Motors页面与安全拒绝

- [ ] Motors页四路顺序为M1前左、M2后左、M3前右、M4后右；`motor_idle=5.5%`读值正确。
- [ ] 未确认安全开关、Configurator未禁ARM、RC ARM高、输入过期或DShot故障时，非零Motor命令全部拒绝。
- [ ] DISARMED且全部门禁满足时，1000停止，1001对应DShot 48，2000对应DShot 2047；四路独立响应正确。
- [ ] 停止拖动、切页、USB断开或停止刷新后不超过250 ms四路归零。
- [ ] Motor Test期间拉高RC ARM立即停止且不能ARM；ARMED状态下连停止帧在内的所有Motor写入均拒绝。
- [ ] 修改`motor_idle`并保存后，只影响正常ARMED飞行端点，不改变Motor Test 48～2047协议端点。

## 8. 参数迁移、保存与掉电

- [ ] 从v1.3.0已有v1参数槽升级启动：加速度偏置保留，新字段采用安全默认值，状态显示`migration_pending=1`。
- [ ] 首次成功保存写入非活动槽v2；复位后加载v2且序号、活动槽和全部字段一致。
- [ ] 模拟保存失败/中断后仍能回退到上一完整槽；未提交记录不会成为活动配置。
- [ ] 保存前ARM或保存排队后抢先ARM均被最终写入点拒绝，Sector 6/7不擦写，运行Profile不改变。
- [ ] 正常保存成功后一次性发布完整Profile；FlightTask复位控制历史，不出现新旧字段混用。
- [ ] 连续多次保存、复位和断电恢复结果一致，无CRC/slot/save错误持续增长。

- [ ] S3及S4.1～S4.7既有真实行为无回归。
