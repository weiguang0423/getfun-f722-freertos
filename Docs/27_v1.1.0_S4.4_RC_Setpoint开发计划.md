文件作用：冻结S4.4 RC归一化、Actual Rates、Expo和AUX模式请求的软件边界与验收口径。
安全边界：本阶段只生成setpoint和模式请求，不实现PID、Mixer、真实ARM或Angle外环，Motor继续只允许显式拆桨测试命令非零。

# v1.1.0 S4.4 RC Setpoint开发计划

> 原候选标签：`v1.1.0-rc-setpoint-baseline`（已并入v1.2.0联合候选，不单独创建）
> 当前状态：软件完成，按开发者要求与S4.5/S4.6统一等待文档30联合验收

## 1. 数据链

```text
CRSF channel_us[]
  -> S3.8 AETR mapped_channel_us[]
  -> S4.4 输入端点裁剪与Deadband
  -> [-1,+1] Roll/Pitch/Yaw + [0,1] Throttle
  -> Betaflight Actual Rates + Expo
  -> rate_dps[3] + ARM/ANGLE请求
  -> app_state.flight.rc_setpoint
```

FlightTask只在RC快照有效且年龄小于300 ms时更新setpoint；RC无效或过期时立即发布全零、
`valid=false`。IMU、参数或电池inhibit不篡改RC计算结果，但后续控制和Motor输出仍必须经过
S4.1完整安全门禁。

## 2. 第一版固定Profile

| 项目 | 值 |
|---|---|
| 输入端点 | 1000 / 1500 / 2000 us |
| Roll/Pitch Deadband | 5 us |
| Yaw Deadband | 5 us |
| Rates类型 | Betaflight Actual，类型3 |
| 中心灵敏度 | Roll/Pitch/Yaw均70 deg/s |
| 最大角速度 | Roll/Pitch/Yaw均670 deg/s |
| Expo | Roll/Pitch/Yaw均0% |
| ARM请求 | AUX1，即映射索引4；1700～2000 us |
| ANGLE请求 | AUX2，即映射索引5；1700～2000 us |
| 默认模式 | RATE |

Profile由`rc_setpoint_default_profile()`作为算法、MSP和诊断的单一数据源。S4.4不新增Flash
记录版本和写命令；App写入、合法性检查、持久化及Armed拒绝统一留给S4.9，避免在没有完整
配置事务时生成半套参数状态。

## 3. 数值契约

轴输入先限制在端点内。中点Deadband内输出0，越过Deadband后把剩余区间重新缩放到
`[-1,+1]`，因此1000/2000 us仍精确对应-1/+1。Throttle只裁剪并线性映射到`[0,1]`。

Actual Rates按三个轴各自的中心灵敏度、最大角速度和Expo计算；默认Profile在满杆输出
`±670 deg/s`。Profile必须满足端点有序、Deadband小于两侧有效行程、AUX索引位于
CH5～CH16、范围位于输入端点内、Expo不超过100%、中心灵敏度不大于最大角速度。

## 4. 软件接口

```c
const rc_setpoint_profile_t *rc_setpoint_default_profile(void);
bool rc_setpoint_profile_is_valid(const rc_setpoint_profile_t *profile);
bool rc_setpoint_compute(
    const rc_setpoint_profile_t *profile,
    const uint16_t mapped_channel_us[RC_INPUT_CHANNEL_COUNT],
    rc_setpoint_output_t *output);
```

`rc_setpoint_compute()`成功时返回`true`并置`output.valid=true`；空指针或非法Profile返回
`false`，且只要`output`有效就先清零，调用者不会拿到旧setpoint。

## 5. 诊断接口

- UART4每秒新增`setpoint`行：valid、mode、arm_req、三轴归一化值、Throttle、三轴目标角速度和计数。
- GETFUN MSP2 `0x4007`返回固定64字节：Profile、setpoint、更新/错误计数、RC序号和年龄。
- 标准`MSP_RC_TUNING`、`MSP_RC_DEADBAND`和`MSP_RX_CONFIG`从同一个默认Profile投影只读值。

## 6. 完成定义

- 纯算法覆盖端点、Deadband、裁剪、Throttle、Actual Rates、Expo和AUX边界。
- FlightTask只消费S3.8映射后的新鲜RC快照，Failsafe后setpoint清零。
- AUX1只生成ARM请求，不能让Motor非零；AUX2只选择RATE/ANGLE请求，不执行Angle外环。
- UART/MSP可观察结果，既有RC、DShot、IMU、姿态和电源回归不退化。
- Debug/Release构建通过，PARAM_A/PARAM_B仍为0 B；文档30联合验收前不创建候选标签。
