## 1. 软件交付结论

本轮已经在v0.5.0的1 kHz DRDY门控DMA链上加入独立微秒时间和低通支路：

```text
DMA完成ISR
  → 捕获DWT CYCCNT
  → ImuTask扩展为uint32微秒时间戳
  → 计算500～2000 µs有效dt
  → SI/CW90和两种校准
  ├─ 未滤波 → MSP_RAW_IMU
  └─ Gyro 100 Hz / Accel 30 Hz PT1
       → filtered_* → 后续Mahony
```

首样本只有时间戳，不具有有效dt；第二个连续有效样本完成滤波更新后才READY。
初始化、恢复、时间源失败、dt超界或非有限计算都会保持独立时间解锁抑制并重置滤波，
不会把异常间隔夹紧后交给未来Mahony。

## 2. 时间实现

### 2.1 DWT时基

`platform_time` 使用Cortex-M7 DWT `CYCCNT`：

- 检查 `SystemCoreClock` 可整除1 MHz。
- 解锁DWT并使能 `TRCENA/CYCCNTENA`。
- ISR只读取原始周期计数。
- ImuTask单写者使用无符号差扩展32位回绕。
- 不足1 µs的周期余数保留到下一次转换。
- 在线按样本维护，离线/DRDY未就绪时至少每1秒维护。

216 MHz下DWT原始回绕时间为19.884108秒；对外 `uint32_t` 微秒时间约71.582788分钟
回绕，间隔计算继续使用无符号减法。

### 2.2 `dt`状态

| 条件 | `timing_valid` | 行为 |
|---|---:|---|
| 时间源未就绪 | 0 | 异常计数增加，清除上一时间，重置滤波 |
| 初始化/恢复后的首样本 | 0 | 建立上一时间，只播种滤波 |
| 500～2000 µs | 1 | 更新min/max并允许低通处理 |
| 小于500或大于2000 µs | 0 | 保留实际间隔诊断，增加异常/重置计数 |
| DRDY未就绪或读取失败 | 0 | 当前快照不允许未来姿态/ARM使用 |

## 3. 低通交付

新增纯C模块：

```text
APP/Inc/algorithms/imu_filter.h
APP/Src/algorithms/imu_filter.c
```

固定参数：

| 支路 | 截止频率 | 1 kHz下alpha |
|---|---:|---:|
| Gyro PT1 | 100 Hz | 约0.38587 |
| Accel PT1 | 30 Hz | 约0.15860 |

离线离散幅相参考结果：

| 支路/频率 | 幅值比 | 相位 |
|---|---:|---:|
| Gyro 20 Hz | 0.968982 | -11.145° |
| Gyro 100 Hz | 0.623123 | -35.657° |
| Accel 5 Hz | 0.983892 | -9.437° |
| Accel 30 Hz | 0.676513 | -42.261° |

参考脚本同时验证三轴常量、500/2000 µs边界、alpha范围、DC/阶跃收敛以及理论/测量
幅相容差。PT1使用后向欧拉形式，因此标称截止频率处的离散幅值不强制等于连续系统
的 `1/sqrt(2)`；验收以表中离散参考为准。

## 4. 状态、MSP与UART

### 4.1 app_state

新增：

- 时间源、当前dt、min/max、异常和重置计数。
- 校准后未滤波的原有 `acceleration_m_s2/angular_rate_rad_s`。
- 新增 `filtered_acceleration_m_s2/filtered_angular_rate_rad_s`。
- `APP_ARMING_INHIBIT_IMU_TIMING_INVALID=0x00000010`。

只有IMU在线、当前dt有效且滤波READY时清除时间抑制。当前版本仍没有真实ARM或
DShot输出。

### 4.2 协议与诊断

- `MSP_RAW_IMU`语义不变，继续使用校准后未滤波数据。
- `MSP_STATUS.cycleTime`在当前dt有效时更新为实际微秒间隔。
- GETFUN MSP2 `0x4000`参数/校准诊断保持不变。
- 新增GETFUN MSP2 `0x4001`固定40字节时间/低通诊断。
- UART 1 Hz增加时间源、当前/min/max dt、异常/重置、固定截止频率和滤波值。

MSP2 `0x4001` flags：

```text
bit0 = DWT time source ready
bit1 = current sample timing valid
bit2 = filter ready
```
