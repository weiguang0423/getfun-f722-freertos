# S5.1 首飞前总体验收与放行清单

> 当前状态：待现场逐项验收。
> 放行规则：所有必选项均为`[x]`且最终记录完整，才允许进入S5.2。
> 中止规则：任一项目失败、结果不确定或现场条件变化，立即DISARM并断开动力电池，S5.1保持未通过。

## 1. 固定边界

- S5之前的阶段与独立关口已由开发者确认全部通过，本清单不重复验收其开发过程。
- 本次使用冻结基线`v1.4.0-angle-app-config-baseline`，任何代码、参数、电机、桨叶、接收机或机架变更都会使相关项目失效，必须重新检查。
- S5.1只做地面静态验收。禁止离地、悬停、带桨Motor Test和大油门测试。
- 首飞固定使用Rate模式、保守参数和低空短时方案；Angle模式留到S5.4。
- 安全优先于记录。出现异常时先DISARM和断电，再记录现象。

## 5. 拆桨功能复核

- [ ] App标准Quad-X编号与真实机架一致：M1后右、M2前右、M3后左、M4前左；固件分别映射到板载输出M4、M3、M2、M1。
- [ ] 四个电机旋转方向与选定的Quad-X桨向一致；必须拆桨，在App“电机→电机方向”中逐个点动确认，不一致时选择该电机的“反向”，等待方向命令和ESC保存命令均完成后断电重上电复核。
- [ ] “反转电机转向”开关只用于整套props-in/props-out布局并同步反转Yaw混控；不要用它修正某一只电机，单电机必须在“电机方向”窗口修改ESC。
- [ ] App保存后固件应回包并自动重启、USB重新连接；不得停留在无限重连或无响应状态。
- [ ] App Motor Test只在DISARMED且确认安全后生效；停止拖动、切页或USB断开后250 ms内全部归零。
- [ ] Roll、Pitch、Yaw摇杆设定方向正确；手动扰动机体时控制修正方向与扰动相反。
- [ ] Rate模式为首飞默认模式；模式开关位置与App显示一致。
- [ ] ARM低位、低油门和全部门禁清零后才能进入DISARMED；ARM高位上电不能自动解锁。
- [ ] 正常ARM/DISARM至少3次，每次DISARM后四路立即归零，无单电机残留。
- [ ] 遥控器关闭或接收链中断会在既定超时内停机；链路恢复后不会自动重新ARM。
- [ ] Configurator禁止解锁、IMU/RC过期、控制无效、DShot故障和系统Fault的停机门禁无回归。
- [ ] 拆桨运行至少5分钟，错误计数不持续增长，电机、ESC和飞控无异常发热。

## 6. RC与首飞参数

- [ ] AETR通道顺序、端点、中位和Deadband正确，通道无跳变或明显漂移。
- [ ] Throttle最低值稳定不高于解锁门限，满量程不越界。
- [ ] AUX1仅控制ARM，AUX2模式位置明确；首飞档固定为Rate。
- [ ] 遥控器Failsafe已设置为不保持旧通道，关闭遥控器时飞控显示RXLOSS并停机。
- [ ] 遥控链路质量稳定，天线方向和首飞距离留有充足余量。

- [ ] 首飞动作约定明确：低油门缓升、只做小幅输入、发现翻转/振荡/方向异常立即DISARM。

## 7. 电池与动力系统

首次接电前保持拆桨，完成基础检查后才进入第8节装桨。

- [ ] 电池无鼓包、破损、漏液或异常温度，插头和线材规格满足动力电流。
- [ ] 电芯数、满电电压和低压阈值与配置一致；电池电压与万用表读数合理一致。
- [ ] 电池固定带和防滑垫完好，安装后插头不会松脱，线缆不进入桨盘。
- [ ] 现场具备立即拔除动力电池的路径，插拔人员不跨越桨盘。
- [ ] 接电无异常火花、气味、声音或发热；电容极性和固定正常。
- [ ] 拆桨低油门短时运行后，四个电机与ESC温升大致一致，无失步、异响或明显振动。
- [ ] 备用电池也逐块完成外观、电压和插头检查，未验收电池不得用于首飞。

- [ ] 每片桨的推力方向与对应电机旋向一致；固定方式和紧固方向正确。

## 9. 场地、人员与应急

- [ ] 场地空旷、地面平整，远离人员、车辆、建筑、树木、架空线和无线电敏感区域。
- [ ] 天气、能见度和风况适合保守低空首飞；没有雨水、强风或阵风风险。
- [ ] 已确认当地飞行限制和场地许可，首飞范围不会越界。
- [ ] 仅保留飞手和安全观察员在作业区，其他人员位于安全线外且飞行器不朝向人员。
- [ ] 飞手站位、机头方向、起飞点和紧急降落区明确。
- [ ] 飞手可不移开视线直接操作DISARM；安全观察员可直接要求中止。
- [ ] 首飞仅使用一块已验收电池，计划为Rate模式贴地短时测试，不追求持续悬停。
- [ ] 异常口令统一为“停机”；听到口令或失去姿态判断时立即DISARM，不尝试挽救设备。
- [ ] 灭火/隔离工具、基础急救用品和电池安全存放位置可用。
- [ ] 已关闭无关人员靠近和手机/相机干扰操作，记录工作不影响安全观察。
