## 4. S4.5/S4.6控制方向

在DISARMED先观察逻辑值，再ARM进行拆桨低油门动态确认：

- [ ] 正Roll设定使Roll correction为正，M1/M2下降、M3/M4上升。
- [ ] 正Pitch设定使Pitch correction为正，M1/M3上升、M2/M4下降。
- [ ] 正Yaw设定使Yaw correction为正，M1/M4上升、M2/M3下降（Betaflight默认Yaw取反）。
- [ ] 摇杆回中，手动产生正Roll/Pitch/Yaw角速度时对应correction和电机对反向，形成恢复方向。
- [ ] ARMED且Throttle大于5%时`int=1`；撤锁或低油门后I项立即为0。
- [ ] 油门离开最低位时D项从当前测量重新播种，随后经75/150 Hz两级PT1，不得因电机振动瞬时打满。
- [ ] correction不越过±500 milli；饱和时四路保持0～1000、相对顺序不反转。
- [ ] M1后右、M2前右、M3后左、M4前左与真实机架位置/旋向一致。

## 5. S4.7状态转换和输出授权

- [ ] ARM高位上电或复位：保持PREARM，四路输出为0，不能自动ARM。
- [ ] ARM低位、原始Throttle不大于1050 us且全部block清零：进入DISARMED，不转动电机。
- [ ] 从DISARMED把ARM切到高位：进入ARMED，`arm_count`增加1；默认无Motor Stop，零归一化油门关闭PID修正并让四路固定输出Betaflight `motor_idle=5.5%`（DShot 158），不得因台架振动抬升任一路。
- [ ] 原始Throttle从1050推到1525/2000 us时，归一化值为0/0.5/1，无PID修正时DShot对应158/1102/2047。
- [ ] 正常把ARM切回低位：同一控制周期撤锁，四路变0，`disarm_count`增加1。
- [ ] ARMED时非零`0x4006`Motor Test被拒绝；已有Motor Test时拉高ARM立即停止测试且不能ARM。
- [ ] Configurator下发禁止解锁时bit 6阻止ARM；若在ARMED下发则进入FAILSAFE并停机。
- [ ] AUX2切ANGLE时，在S4.8完成前bit 8阻止ARM；ARMED中切换则FAILSAFE停机。
- [ ] ARMED时加速度校准命令被拒绝，参数Sector 6/7不发生擦写。

## 6. Failsafe与故障停机

每项都从拆桨低油门ARMED开始，发生后确认四路为0、`last_fs`保留对应位、
`flight_failsafe_count`只增加一次；恢复后ARM保持高位不能自动重解锁：

- [ ] 关闭遥控器/接收链：300 ms边界触发RC invalid/stale并停机。
- [ ] 单次DRDY未就绪只增加`not_ready`并保留上一有效快照；连续超过5 ms没有新IMU样本才触发IMU stale并停机。
- [ ] 任一`arming_inhibit_flags`重新出现：触发统一inhibit并停机。
- [ ] DShot DMA/提交故障：GPIO立即低电平、DShot故障锁存到重启并停机。
- [ ] 系统fault标志非0：进入FAILSAFE并停机；平台致命Fault继续走底层硬停机。
- [ ] 故障恢复后先把ARM切低进入PREARM，再确认block为0进入DISARMED；随后新的ARM高位才允许重解锁。
- [ ] ARMED状态复位/断电后输出立即消失；ARM仍高位重启不会自动ARM。
