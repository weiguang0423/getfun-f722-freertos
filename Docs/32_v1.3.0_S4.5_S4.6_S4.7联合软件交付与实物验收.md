## 5. S4.7状态转换和输出授权

- [x] ARM高位上电或复位：保持PREARM，四路输出为0，不能自动ARM。
- [x] ARM低位、原始Throttle不大于1050 us且全部block清零：进入DISARMED，不转动电机。
- [x] 从DISARMED把ARM切到高位：进入ARMED，`arm_count`增加1；默认无Motor Stop，零归一化油门让Mixer修正缩放为0并让四路固定输出Betaflight `motor_idle=5.5%`（DShot 158），不得因台架振动抬升任一路。
- [x] 原始Throttle从1050推到1525/2000 us时，归一化值为0/0.5/1，无PID修正时DShot对应158/1102/2047。
- [x] 正常把ARM切回低位：同一控制周期撤锁，四路变0，`disarm_count`增加1。
- [x] ARMED时非零`0x4006`Motor Test被拒绝；已有Motor Test时拉高ARM立即停止测试且不能ARM。
- [x] Configurator下发禁止解锁时bit 6阻止ARM；若在ARMED下发则进入FAILSAFE并停机。
- [x] AUX2切ANGLE时，在S4.8完成前bit 8阻止ARM；ARMED中切换则FAILSAFE停机。
- [x] ARMED时加速度校准命令被拒绝，参数Sector 6/7不发生擦写。

## 6. Failsafe与故障停机

每项都从拆桨低油门ARMED开始，发生后确认四路为0、`last_fs`保留对应位、
`flight_failsafe_count`只增加一次；恢复后ARM保持高位不能自动重解锁：

- [x] 关闭遥控器/接收链：300 ms边界触发RC invalid/stale并停机。
- [x] 单次DRDY未就绪只增加`not_ready`并保留上一有效快照；连续超过5 ms没有新IMU样本才触发IMU stale并停机。
- [x] 任一`arming_inhibit_flags`重新出现：触发统一inhibit并停机。
- [x] DShot DMA/提交故障：GPIO立即低电平、DShot故障锁存到重启并停机。
- [x] 系统fault标志非0：进入FAILSAFE并停机；平台致命Fault继续走底层硬停机。
- [x] 故障恢复后先把ARM切低进入PREARM，再确认block为0进入DISARMED；随后新的ARM高位才允许重解锁。
- [x] ARMED状态复位/断电后输出立即消失；ARM仍高位重启不会自动ARM。
