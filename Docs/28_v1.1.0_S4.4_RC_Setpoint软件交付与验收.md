## 3. 真实RC验收

上电后观察UART4的`rc`、`flight`和`setpoint`三行，或读取GETFUN MSP2 `0x4007`：

- [ ] RC恢复健康后`setpoint valid=1`且`errors=0`。
- [ ] Roll/Pitch/Yaw中点及±5 us内为0；离开Deadband后符号与遥控方向一致。
- [ ] 三轴低端接近-1000、高端接近+1000；无论CRSF略超端点都不越界。
- [ ] Throttle低端为0、高端为1000，范围外输入被裁剪。
- [ ] 默认Actual Rates满杆分别接近-670000/+670000 mdps，中点附近连续且无跳变。
- [ ] AUX1进入1700～2000 us时只有`arm_req=1`，Motor仍保持0。
- [ ] AUX2进入1700～2000 us时`mode=1`，退出后回到`mode=0`；本阶段Motor仍保持0。
- [ ] RC断链达到300 ms后`valid=0`、stick/throttle/rate全零；恢复需继续满足S3.8的100 ms+5帧门禁。

## 4. App只读投影
