# GETFUN_F722 飞控 APP 层 — 系统逻辑管道图

按数据流/控制流从左到右分 5 个阶段：**感知 → 解算 → 控制 → 接口/状态 → 支撑**。

```mermaid

  subgraph SENSE["感知"]
    IMU["IMU 采样\n(SPI1/ICM42688P, 1kHz DMA)"]
    TIME["时间基准\n(DWT 微秒 dt)"]
  end

  subgraph EST["解算"]
    CAL["校准\n(陀螺零偏 / 加速度)"]
    FILT["低通滤波\n(PT1, 真实 dt)"]
    ATT["姿态估计\n(Mahony 四元数)"]
  end

  subgraph CTRL["控制"]
    RC["RC 输入\n(CRSF + 虚拟 RC 仲裁)"]
    FC["飞行控制\n(ANGLE 外环 + Rate PID + 安全链)"]
    MIX["混控\n(Quad-X)"]
    MOT["电机输出\n(8 路安全输出)"]
  end

  subgraph IFACE["接口 / 状态"]
    STATE["全局状态\n(app_state 快照)"]
    MSP["MSP / USB 通信\n(Betaflight 遥测)"]
    PARAM["参数存储\n(Flash Sector 6/7)"]
  end

  subgraph SUPP["支撑"]
    INIT["应用装配\n(任务创建与初始化)"]

  end

  %% 装配：创建并启动各任务
  INIT --> IMU
  INIT --> RC
  INIT --> FC
  INIT --> PWR
  INIT --> MSP
  INIT --> STATE

  %% 主信号链
  IMU --> CAL
  CAL --> FILT
  FILT --> ATT
  ATT --> FC
  RC --> FC
  FC --> MIX
  MIX --> MOT
  FC --> MOT

  %% 时间基准贯穿
  TIME --> IMU
  TIME --> FILT
  TIME --> ATT

  %% 全局状态：发布与读取
  IMU --> STATE
  CAL --> STATE
  FILT --> STATE
  PWR --> STATE
  STATE --> FC
  STATE --> MSP

  %% 参数持久化
  CAL --> PARAM
  PARAM --> CAL
  MSP --> PARAM

  %% 诊断安全停机
  DIAG --> MOT
```

## 读图说明

- **实线箭头** = 数据/控制流向（谁把数据交给谁）。
- **主信号链**：`IMU采样 → 校准 → 低通滤波 → 姿态估计 → 飞行控制 → 混控 → 电机输出`，这是飞控的核心闭环。
- **时间基准**从上方贯穿采样、滤波、姿态三处，提供真实 `dt`。
- **RC 输入**在飞行控制处汇入主链（设定值来源）。
- **全局状态**是各模块发布、飞行控制与 MSP 读取的中枢；**参数存储**持久化校准零偏与配置；**诊断**在故障/保存前强制电机低电平。
