# S7.4 板端实时手部识别与屏显复现指南

本文档记录如何在一台新的 Windows/WSL 电脑上，复现 RK3568 开发板上的实时手部识别与 DSI/LED 屏幕显示。

复现目标：在开发板上运行摄像头实时手部识别（MediaPipe 风格的两级 FP16 RKNN 模型），并把检测框、21 个手部关键点、presence/handedness 信息实时叠加显示到连接的屏上。

---

## 1. 适用环境

- 开发板：ATK-DLRK3568 / RK3568，AArch64
- 板端系统：Linux 4.19.232
- 屏幕：DSI 屏，`720x1280@60Hz`，DRM 节点 `/dev/dri/card0`
- 摄像头：IMX335，V4L2 节点 `/dev/video0`
- 模型：FP16 手部检测 + 手部关键点模型
- 板端已有程序：
  - `/userdata/s7_4_live`
  - `/userdata/s7_4_drm_smoke`
  - `/userdata/s7_3_acceptance/s7_3_deploy_20260813/models/fp16/hand_detector_fp16.rknn`
  - `/userdata/s7_3_acceptance/s7_3_deploy_20260813/models/fp16/hand_landmarks_detector_fp16.rknn`
  - OpenCV 运行库目录：`/userdata/s7_3_acceptance/s7_3_deploy_20260813/lib`

> 如果板端没有这些文件，需要先从之前的部署包/另一台电脑拷贝，或者使用 RK3568 SDK 交叉编译生成 `s7_4_live`。

---

## 2. 硬件连接

1. 开发板通电并启动到 Linux。
2. DSI 屏连接开发板。
3. 摄像头连接开发板。
4. 串口线连接电脑和开发板调试串口（例如 CH340 转串口，电脑上可能显示为 `COM9`）。
5. 网线连接电脑的 USB 千兆网卡（ASIX AX88179）和开发板网口，用于 SSH 和文件传输。

实际复现时观察到的网络：

| 位置 | IP |
|---|---|
| 电脑/WSL 直连网卡 | `169.254.197.77/16` |
| 开发板 eth1 | `169.254.212.3/16` |

> 注意：早期文档写的板端 IP 是 `169.254.151.86`，这次实际板子是 `169.254.212.3`。请以板端 `ip addr` 实际输出为准。

## 3. 登录开发板

### 3.1 串口登录

- 串口号：以 Windows 设备管理器为准，实际为 `COM9`
- 波特率：`1500000`
- 用户名：`root`
- 密码：按实际板子配置

也可以使用命令快速探测：

```powershell
powershell -Command "$p=New-Object System.IO.Ports.SerialPort 'COM9',1500000,None,8,one; $p.Open(); Start-Sleep -Milliseconds 200; $p.Write(\"`r\"); Start-Sleep -Milliseconds 500; $p.ReadExisting(); $p.Close()"
```

进入后应看到类似：

```text
root@ATK-DLRK3568:/#
```

### 3.2 SSH 登录（推荐）

先在板端确认 IP：

```sh
ip addr
```

例如看到：

```text
eth1: inet 169.254.212.3/16 ...
```

然后在电脑/WSL 中：

```sh
ssh root@169.254.212.3
```

如果需要配置免密，把电脑公钥追加到板端：

```sh
mkdir -p /root/.ssh
echo 'ssh-ed25519 AAAA... your@email' >> /root/.ssh/authorized_keys
chmod 700 /root/.ssh
chmod 600 /root/.ssh/authorized_keys
```

## 4. 板端前置检查

通过 SSH 或串口执行：

```sh
# 确认系统
uname -a

# 确认网络
ip addr

# 确认 DRM/屏幕
ls -l /dev/dri/
for d in /sys/class/drm/card0-*; do
  echo "--- $d"
  cat "$d/status"
  cat "$d/modes"
done

# 确认摄像头
ls -l /dev/video*

# 确认运行文件存在
ls -l /userdata/s7_4_live
ls -l /userdata/s7_4_drm_smoke
ls -l /userdata/s7_3_acceptance/s7_3_deploy_20260813/models/fp16/
```

预期关键结果：

- DSI 屏：`/sys/class/drm/card0-DSI-1/status` 为 `connected`，mode 为 `720x1280`
- 摄像头：存在 `/dev/video0`
- 运行文件均存在

## 5. 释放 DRM 显示权限

板端默认可能运行 Weston，占用 DRM master。直接跑 DRM 显示程序前必须停止 Weston：

```sh
killall weston
```

确认没有 Weston 进程：

```sh
ps aux | grep -i weston | grep -v grep
```

## 6. 屏显冒烟测试

先验证屏幕链路是否可用：

```sh
cd /userdata
./s7_4_drm_smoke /dev/dri/card0 10
```

预期输出：

```text
smoke: /dev/dri/card0: 2 crtc, 2 connector, 3 encoder
...
smoke: displaying 720x1280@60Hz on crtc 115 fb 164 for 10 s
...
smoke: ok, display link usable
```

同时屏幕应显示渐变色块 10 秒。

## 7. 运行实时手部识别 + 屏幕显示

### 7.1 短时验证（跑 10 秒）

```sh
cd /userdata

./s7_4_live \
  --camera \
  /userdata/s7_3_acceptance/s7_3_deploy_20260813/models/fp16/hand_detector_fp16.rknn \
  /userdata/s7_3_acceptance/s7_3_deploy_20260813/models/fp16/hand_landmarks_detector_fp16.rknn \
  /dev/video0 800 600 20 10 200 4776 \
  /userdata/annot_repro 5 \
  /dev/dri/card0
```

参数说明：

| 参数 | 含义 |
|---|---|
| `800 600` | 摄像头采集宽高 |
| `20` | 目标 fps |
| `10` | 运行秒数，`0` 表示持续运行 |
| `200` | 最大端到端延迟，超过则本帧标为无效 |
| `4776` | 摄像头 vertical_blanking，`-1` 表示不修改 |
| `/userdata/annot_repro` | 标注帧输出目录 |
| `5` | 每 5 帧保存一张标注图 |
| `/dev/dri/card0` | DRM 显示设备 |

### 7.2 持续运行（推荐，实时显示）

```sh
cd /userdata

nohup ./s7_4_live \
  --camera \
  /userdata/s7_3_acceptance/s7_3_deploy_20260813/models/fp16/hand_detector_fp16.rknn \
  /userdata/s7_3_acceptance/s7_3_deploy_20260813/models/fp16/hand_landmarks_detector_fp16.rknn \
  /dev/video0 800 600 20 0 200 4776 \
  /userdata/live_annot 5 \
  /dev/dri/card0 \
  >/userdata/live_display.jsonl \
  2>/userdata/live_display.log \
  </dev/null &
```

启动后可查看：

```sh
# 进程是否在运行
ps aux | grep s7_4_live | grep -v grep

# 运行日志
tail -f /userdata/live_display.log

# 实时结果
tail -f /userdata/live_display.jsonl

# 统计有效手部帧
grep -c '"valid":true' /userdata/live_display.jsonl
```

屏幕上应实时显示摄像头画面，并在检测到手时叠加：

- 绿色检测框
- 黄色手部骨架
- 红色关键点
- 左上角 `seq / valid / presence / handed`

## 8. 停止程序

```sh
# 按 PID 停止
kill <PID>

# 或按名称停止
pkill -f s7_4_live
```

停止后如需恢复桌面显示，可重新启动 Weston（按板端原始启动方式），或重启开发板。

## 9. 常见问题

### 9.1 SSH 连不上

- 先确认板端 `ip addr` 中的实际 IP。
- 确认电脑和板端在同一个 `169.254.x.x/16` 直连网段。
- 确认串口已连接并能在板端看到 Linux 提示符。
- 可以在板端手动配置：
  ```sh
  ifconfig eth1 169.254.212.3 netmask 255.255.0.0 up
  ```

### 9.2 屏幕不显示

- 确认已 `killall weston`。
- 确认 `/sys/class/drm/card0-DSI-1/status` 是 `connected`。
- 先跑 `s7_4_drm_smoke`，如果冒烟不通过，说明 DRM/屏幕链路有问题，先修屏幕再跑识别。

### 9.3 启动 `s7_4_live` 后 SSH 命令“卡住”

- 如果使用 `nohup ... &` 启动后台进程，SSH 可能因为后台任务未完全脱离而等待，这是正常的。
- 只要板端 `ps aux | grep s7_4_live` 能看到进程，并且日志在增长，就表示已经在运行。
- 可以在另一个 SSH/串口窗口里查看日志，不必等待启动命令返回。

### 9.4 没有检测到手

- 把手伸入摄像头视野，不要离太远或太快。
- 查看 JSONL 中是否持续输出 `no_hand`。
- 可通过标注图确认画面内容：
  ```sh
  ls -l /userdata/live_annot/
  ```

### 9.5 板端缺少文件

如果板端没有 `s7_4_live`、模型或 OpenCV 库，需要从之前跑通的电脑/部署包拷贝到板端，或在本机准备好 RK3568 SDK 后按 `Linux/RK3568/s7_4/README.md` 交叉编译。
