# S7.3 RKNN转换与板端NPU推理验收记录

## 1. 结论

2026-08-13已完成主机侧转换环境、FP16/INT8模型、ARM64板端程序、固定同字节测试语料、PC参考
结果、误差比较和资源监测工具。2026-08-14在ATK-DLRK3568上完成FP16和INT8各2859帧全量推理，
两次退出码均为0。FP16通过全部冻结误差门槛；INT8虽更快，但有效性一致率及多项P95误差超限，
