# GETFUN F722 V3 v0.1.0 平台基线软件交付与实物验收

> 软件构建日期：2026-07-24  
> 软件状态：编译与静态检查通过，等待实物验收  
> 安全要求：全程拆除螺旋桨；首次测试不连接电机动力电源

---

## 1. 本轮软件交付

- [x] UART4 输出固件身份、构建时间和运行时时钟。
- [x] InitTask 输出一次 `RTOS: started`，随后每约 1 秒输出心跳。
- [x] 心跳包含 RTOS tick、当前/历史最低空闲堆和 InitTask 栈余量。
- [x] Motor 1～8 在平台初始化时被再次强制配置为低电平 GPIO。
- [x] HAL 错误、CPU Fault、FreeRTOS assert、栈溢出和内存分配失败统一进入安全停机。
- [x] 安全停机时强制 Motor 1～8 为低电平。
- [x] 故障码、断言文件和行号可通过 SWD 查看。
- [x] PA10 的错误标签 `MOTOR3` 已修正为 `MOTOR2`。
- [x] Debug 与 Release 均自动生成 ELF、HEX、BIN 和 MAP。

本轮没有实现 IMU、CRSF、ADC、姿态估计、控制器或 DShot；这些功能必须等本文件的实物验收全部通过后再开始。

串口参数：115200、8N1、3.3 V TTL。不要连接 USB-TTL 的电源脚给飞控供电。

```text

HCLK: 216000000
PCLK1: 54000000

RTOS: started
heartbeat tick=... heap=... min_heap=... init_stack_min=...
```

验收时应确认：

- `RTOS: started` 只出现一次。
- `tick` 每秒约增加 1000。
- `min_heap` 和 `init_stack_min` 不持续下降。
- 连续运行 30 分钟没有复位、卡死或心跳中断。

## 4. SWD 故障码

发生故障后，CPU 会关闭中断并停在安全循环中。通过调试器读取：

```text
g_platform_fault_code
g_platform_fault_file
g_platform_fault_line
```

| 故障码 | 含义 |
|---:|---|
| 0 | 无故障 |
| 1 | HAL/Error_Handler |
| 2 | FreeRTOS 栈溢出 |
| 3 | FreeRTOS 内存分配失败 |
| 4 | FreeRTOS/configASSERT；同时查看文件和行号 |
| 5 | HardFault |
| 6 | MemManage Fault |
| 7 | BusFault |
| 8 | UsageFault |
| 9 | 调度器意外返回 |
