# GETFUN F722 V3 v0.2.0 IMU轮询基线软件交付与实物验收

> 软件构建日期：2026-07-27  
> 软件状态：Debug/Release 构建与静态核查通过，等待实物验收

## 1. 本轮软件交付

- [x] SPI1 Master、Mode 0、8 bit、MSB first、1.6875 MHz。
- [x] PA5 SCK、PA6 MISO、PA7 MOSI、PA4软件CS。
- [x] PA4在GPIO初始化时默认高电平。
- [x] 同版本 STM32Cube FW F7 V1.17.4 官方SPI HAL源码。
- [x] `imu_bus`统一管理CS、32字节长度上限、5 ms超时和HAL错误映射。
- [x] ICM42688P软件复位、WHO_AM_I、固定配置、回读和14字节突发读取。
- [x] 静态ImuTask：512 words、`tskIDLE_PRIORITY+4`、1 tick周期。
- [x] 加速度、角速度、温度SI单位转换。
- [x] `CW90_DEG`软件轴向转换，实物方向仍待确认。
- [x] 三次连续读取失败离线、三次初始化尝试和1秒后台恢复。
- [x] `app_imu_sample_t`完整快照与单写者发布。
- [x] `MSP_STATUS/STATUS_EX`在线传感器位。
- [x] `MSP_RAW_IMU`真实数据转换、`int16_t`饱和和离线清零。
- [x] InitTask降为`osPriorityIdle`并输出1 Hz IMU摘要。
- [x] Motor 1～8安全GPIO逻辑未改为定时器或有效输出。

本轮没有实现DMA、FIFO、外部DRDY中断、校准、滤波、姿态解算、PID、CRSF或DShot。

## 3. 预期UART输出

串口：UART4，115200，8N1，3.3 V TTL。

启动段应包含：

```text
GETFUN F722 FreeRTOS
MCU: STM32F722RET6
BUILD: ...
SYSCLK: 216000000
HCLK: 216000000
PCLK1: 54000000
PCLK2: 108000000
MOTORS: safe GPIO low
IMU: SPI1 1687500 Hz mode=0 polling
RTOS: starting
RTOS: started
```

每秒应输出三行：

```text
heartbeat tick=... heap=... min_heap=... init_stack_min=...
imu present=... who=0x.. status=... bus=... hz=... samples=... init_errors=... read_errors=... not_ready=... missed=...
imu acc_mm_s2=[...,...,...] gyro_mrad_s=[...,...,...] temp_mc=... imu_stack_min=... cfg=[..,..,..]
```

正常在线的核心特征：

```text
present=1
who=0x47
status=0
bus=0
cfg=[06,06,0F]
```

第一轮心跳可能发生在ImuTask完成初始化之前，因此第一条IMU摘要为零不代表失败；应观察后续摘要。

## 4. 状态码

### ICM42688P驱动状态 `status`

| 值 | 含义 |
|---:|---|
| 0 | 正常 |
| 1 | 参数错误 |
| 2 | 总线错误 |
| 3 | WHO_AM_I不是`0x47` |
| 4 | 配置回读不一致 |

### IMU总线状态 `bus`

| 值 | 含义 |
|---:|---|
| 0 | 正常 |
| 1 | 参数错误 |
| 2 | SPI1未就绪 |
| 3 | HAL_ERROR |
| 4 | HAL_BUSY |
| 5 | HAL_TIMEOUT |

## 6. SPI波形验收

逻辑分析仪连接PA4、PA5、PA6、PA7：

- [x] 空闲时CS为高。
- [x] SCK空闲为低。
- [x] 数据在Mode 0下采样。
- [x] SCK约为1.6875 MHz。
- [x] 每个寄存器事务只有一个连续的CS低窗口。
- [x] 14字节读取包含1字节地址和14字节数据。
- [x] WHO_AM_I读取返回`0x47`。
- [x] 人为通信失败后CS仍回到高电平。

建议额外执行WHO_AM_I 1000次稳定性检查；当前常规固件不会逐次打印，必要时使用SWD断点或临时测试构建，测试结束后恢复正式固件。

## 7. 静态数据和方向验收

水平静止：

- [x] 三轴加速度合成值约为`9.32～10.30 m/s²`。
- [x] 静止角速度没有持续的大幅偏置或跳变。
- [x] 温度处于合理环境范围。
- [x] 数据变化连续，不是固定全0、全`0xFF`或周期性突变。

六面放置：

- [x] 机体X正方向朝上时，X轴约为`+9.81 m/s²`。
- [x] 机体X负方向朝上时，X轴约为`-9.81 m/s²`。
- [x] 机体Y正/负方向结果符合定义。
- [x] 机体Z正/负方向结果符合定义。

角速度：

- [x] 主要绕机体X轴转动时X响应最大。
- [x] 主要绕机体Y轴转动时Y响应最大。
- [x] 主要绕机体Z轴转动时Z响应最大。
- [x] 正负方向符合项目机体坐标约定。

如果方向不符，只修改统一的板级轴变换，不能分别给加速度和陀螺使用不同映射。

- [x] 正常运行时`read_errors`不增长。

## 9. 故障和恢复验收

上电缺失：

- [x] 断开或阻断IMU后上电，`present=0`。
- [x] `init_errors`每轮增加。
- [x] 平台心跳、UART和USB继续工作。
- [x] Motor 1～8保持低电平。

运行中故障：

- [x] 在线后人为造成连续读取失败。
- [x] 三次连续失败后`present=0`。
- [x] `read_errors`和状态码能够反映故障。
- [x] 恢复连接后约1秒内重新初始化。
- [x] 恢复后`who=0x47`、`cfg=[06,06,0F]`、`present=1`。
- [x] 累计错误计数不会因为恢复而清零。
