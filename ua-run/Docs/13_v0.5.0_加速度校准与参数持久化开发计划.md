# v0.5.0 加速度校准与参数持久化开发计划

> 上一基线：`v0.4.0-gyro-calibration-baseline`（`758d424`）<br>
> 目标标签：`v0.5.0-accel-calibration-params-baseline`<br>
> 当前状态：✅ 真实硬件验收通过，冻结为v0.5.0基线<br>
> 目标硬件：STM32F722RET6，512 KB内部Flash

## 1. 目标与数据流

本阶段建立第一版通用参数持久化底座，并完成ICM42688P机体系加速度水平单面校准。

```text
ICM42688P原始数据
  → SI单位
  → CW90机体系
  → 陀螺校准/扣偏
  → 加速度水平校准（使用未扣加速度偏置的机体系数据）
  → 加载并应用已提交的加速度偏置
  → app_state / MSP / 后续Mahony
```

加速度偏置只能在SI换算和 `CW90` 之后计算。校准候选值必须先成功写入参数槽并读回
验证，之后才能成为当前有效偏置。

## 2. 实现来源策略

| 内容 | 来源策略 | 结论 |
|---|---|---|
| STM32F722扇区与Flash操作 | ST器件资料与HAL | 使用Sector 6/7和HAL擦写接口 |
| 参数记录、A/B提交与回退 | 参考成熟嵌入式事务记录设计后自主实现 | 项目控制格式、序号、提交标记和安全策略 |
| CRC32 | IEEE CRC-32成熟算法的项目内精简实现 | 不引入大型库，不依赖尚未配置的CRC外设 |
| 水平单面加速度校准 | 参考成熟飞控校准方法后自主实现 | 使用连续静止窗口、Welford统计和水平拒绝 |
| MSP入口 | Betaflight MSP协议 | 实现标准 `MSP_ACC_CALIBRATION`（205） |
| 状态观测 | 项目自主实现 | UART 1 Hz摘要和GETFUN自定义MSP2状态命令 |

本阶段不新增第三方源代码目录。

## 3. Flash布局

STM32F722RET6内部Flash固定为：

| 区域 | 地址 | 大小 | 用途 |
|---|---|---:|---|
| 程序区 | `0x08000000`～`0x0803FFFF` | 256 KB | 向量表、代码、只读数据和.data装载值 |
| 参数槽A | `0x08040000`～`0x0805FFFF` | 128 KB | Sector 6，一份已提交参数记录 |
| 参数槽B | `0x08060000`～`0x0807FFFF` | 128 KB | Sector 7，一份已提交参数记录 |

链接脚本必须把 `FLASH` 长度从512 KB限制为256 KB，并导出两个参数槽的起止符号。
链接器区域溢出必须直接导致构建失败，固件不得侵入参数区。

采用两个完整擦除扇区是为了满足掉电安全：

1. 保留当前活动槽。
2. 擦除非活动槽。
3. 写入新记录主体和CRC。
4. 读回并验证主体。
5. 最后写入提交标记。
6. 再次读回验证后切换活动槽。

任何步骤失败都继续使用旧活动槽。不能为了节省Flash改成“先擦除唯一有效记录”。

## 4. 参数记录格式

v1记录固定为48字节、自然4字节对齐：

| 偏移 | 字段 | 大小 | 说明 |
|---:|---|---:|---|
| 0 | magic | 4 | `0x47465052` |
| 4 | version | 2 | `1` |
| 6 | length | 2 | `48` |
| 8 | sequence | 4 | 单调序号，0保留 |
| 12 | flags | 4 | bit0表示加速度校准有效 |
| 16 | accel_bias_m_s2[3] | 12 | CW90机体系三轴偏置 |
| 28 | reserved[3] | 12 | 必须写0，供兼容扩展 |
| 40 | crc32 | 4 | 覆盖偏移0～39 |
| 44 | commit | 4 | `0x434F4D54`，最后写入 |

记录有效条件：

- commit、magic、version和length全部匹配。
- sequence不为0。
- 只包含已知flags。
- 三轴偏置全部有限且绝对值不超过 `0.2 g`。
- CRC32匹配。

两槽都有效时选择序号较新的记录；一槽有效、一槽空白或损坏时使用有效槽；两槽空白时
加载安全默认值；没有有效槽且存在非空损坏记录时加载默认值并设置参数损坏抑制。

## 5. 加速度校准

### 5.1 状态

| 状态 | 含义 |
|---|---|
| `NOT_CALIBRATED` | 没有已提交的加速度偏置 |
| `READY` | 已加载并应用有效偏置 |
| `CALIBRATING` | 正在累计连续水平静止窗口 |
| `CANDIDATE_READY` | 算法完成，等待Flash提交 |
| `SAVE_FAILED` | 算法完成但持久化失败，保持解锁抑制 |

重新校准期间可以继续应用旧偏置，但状态不是READY，因此仍禁止未来ARM。只有新记录
成功提交并读回验证后，才用新偏置替换旧偏置并回到READY。

### 5.2 固定门限

| 参数 | 固定值 |
|---|---:|
| 连续静止预热 | 250样本 |
| Welford统计窗口 | 2000样本 |
| 理论最短时间 | 约2.25秒（1 kHz） |
| 单轴角速度上限 | 5 deg/s |
| 瞬时加速度模长 | 0.8 g～1.2 g |
| 瞬时水平分量 | 不超过0.12 g |
| 最终均值水平分量 | 不超过0.08 g |
| 最终Z绝对值 | 0.9 g～1.1 g |
| 单轴窗口标准差 | 不超过0.03 g |
| 单轴偏置绝对值 | 不超过0.2 g |

目标重力方向根据Z均值符号取 `+g` 或 `-g`：

```text
bias_x = mean_x
bias_y = mean_y
bias_z = mean_z - sign(mean_z) * g
```

这样可以得到与正放/反放无关的零偏，但任何明显倾斜都必须拒绝，不能把重力水平分量
吸收到偏置。

## 6. MSP与状态发布

- 标准 `MSP_ACC_CALIBRATION`（205）：空负载；只有IMU在线、陀螺READY且当前未在校准时接受。
- 自定义MSP2 `0x4000`：返回参数加载、保存、活动槽、序号、校准状态、进度、拒绝计数、
  解锁抑制和三轴偏置，供脚本与后续工具诊断。
- UART 1 Hz摘要增加相同关键状态。

新增解锁抑制：

| 标志 | 条件 |
|---|---|
| `APP_ARMING_INHIBIT_ACCEL_NOT_CALIBRATED` | 加速度状态不是READY |
| `APP_ARMING_INHIBIT_PARAMETERS_INVALID` | 参数区存在损坏且没有可恢复有效记录 |

当前版本仍没有真实ARM/DShot输出。Flash保存前继续强制Motor 1～8为安全低电平；未来
ARM状态机接入后，Armed状态必须拒绝所有内部Flash擦写。
