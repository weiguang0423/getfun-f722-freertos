# v0.7.0 Mahony四元数姿态软件交付及实物验收

> 目标标签：`v0.7.0-mahony-attitude-baseline`<br>
> 前置基线：`v0.6.0-imu-filter-timing-baseline`<br>

## 1. 软件交付结论

S3.6软件链已经实现：

```text
校准后滤波IMU + 真实dt
  → 六轴Mahony
  → Body→NED单位四元数
  → Roll/Pitch/Yaw
  → app_state READY/诊断/解锁抑制
  → MSP_ATTITUDE + MSP2 0x4002 + UART
```

纯C核心不依赖HAL/RTOS，ImuTask仍为单写者。时间、滤波或校准无效时不会积分，
姿态立即失效；恢复后由当前重力方向重新播种Roll/Pitch，Yaw从0重新开始。

## 3. 固定接口摘要

### 3.1 坐标

- 机体系FRD、地理系NED。
- 四元数 `[w,x,y,z]` 表示Body→NED。
- Roll右倾正、Pitch抬头正、Yaw从上看顺时针正。
- 水平正面朝上时加速度比力约 `[0,0,-g]`，算法使用 `-accel` 作为向下重力观测。

### 3.2 输入门控

姿态更新要求同时满足：

- `imu.present=1`
- Gyro校准READY
- Accel校准READY
- `timing_valid=1`
- `filter_ready=1`
- `dt=500～2000 µs`
- 滤波Gyro/Accel全部有限

Accel模长不在0.8～1.2 g时不使用重力反馈，但仍允许有效Gyro积分并累计
`accel_reject/gyro_only`。

### 3.3 输出

- `MSP_ATTITUDE`：Roll/Pitch 0.1°有符号，Yaw 1°且范围0～359。
- 姿态无效时 `MSP_ATTITUDE` 返回 `[0,0,0]`。
- MSP2 `0x4002` 固定52字节，返回READY、五个计数、四元数和毫度Euler。
- `APP_ARMING_INHIBIT_ATTITUDE_NOT_READY` 在姿态无效时保持置位。

### 4.4 静态栈帧

Debug `-fstack-usage` 关键结果：

| 函数 | 静态帧 |
|---|---:|
| `attitude_estimator_update` | 120 B |
| `seed_from_gravity` | 56 B |
| `imu_task` | 264 B |
| `msp_server_process` | 360 B |
| `platform_diag_heartbeat` | 712 B |

这些是单函数静态帧，不等于完整最坏调用链；ImuTask仍配置512 words。最终判据为
真实硬件 `imu_stack_min >= 128 words`，静态结果不能替代运行时高水位。

## 5. 烧录前安全条件

1. 拆除全部螺旋桨。
2. 断开Motor动力电源，仅保留飞控供电、UART4、USB和SWD。
3. 使用本次Debug镜像，保留完整1 Hz日志。
4. 确认加速度校准已READY；否则姿态按设计保持无效。
5. 不得用调整App符号、交换MSP字段或修改CW90来掩盖方向错误。
