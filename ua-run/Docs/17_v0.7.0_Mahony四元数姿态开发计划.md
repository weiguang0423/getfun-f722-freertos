# v0.7.0 Mahony四元数姿态开发计划

> 目标标签：`v0.7.0-mahony-attitude-baseline`<br>
> 所属里程碑：S3.6<br>
> 当前状态：🟠 软件完成，待真实硬件验收

## 1. 目标与边界

在S3.5已验收的校准后滤波IMU和真实 `dt` 上，实现无磁力计的六轴Mahony姿态：

```text
ICM42688P
  → SI单位 + CW90机体系
  → Gyro零偏 / Accel偏置
  → Gyro 100 Hz + Accel 30 Hz PT1
  → Mahony六轴四元数
  → app_state姿态快照
  ├─ MSP_ATTITUDE → Betaflight App三维模型
  ├─ GETFUN MSP2 0x4002
  └─ UART 1 Hz摘要
```

本阶段只建立可冻结的姿态输入/输出边界。没有磁力计，因此Roll/Pitch由重力长期
约束，Yaw只由陀螺积分，允许缓慢漂移。

## 2. 实现来源决策

- 数学结构参考 Mahony、Hamel、Pflimlin 的非线性互补滤波论文：
  `10.1109/TAC.2008.923738`。
- MSP字段顺序和缩放对照Betaflight官方 `msp_protocol.h` 与 `msp.c`：
  `MSP_ATTITUDE=108`，依次为Roll 0.1°、Pitch 0.1°、Heading 1°。
- 加速度可信门和积分高转速抑制参考成熟飞控的工程经验，但代码按本项目坐标、
  单位、失效恢复和测试边界自主实现，不引入大型姿态库或复制第三方模块。
- 新模块只依赖C标准库数学函数，无HAL、RTOS、日志、动态内存和全局状态。

参考链接：

## 3. 坐标、四元数和符号冻结

### 3.1 机体系与地理系

| 项目 | 冻结语义 |
|---|---|
| 机体系 | FRD：X前、Y右、Z下 |
| 地理系 | NED：X北、Y东、Z下 |
| 正旋转 | 绕各轴按右手定则 |
| Roll正 | 右侧机翼/机体右侧向下 |
| Pitch正 | 机头向上 |
| Yaw正 | 从上方看顺时针，机头向右 |
| 角速度 | 机体系 `rad/s` |
| 加速度 | 校准后的机体系比力 `m/s²` |
| 四元数 | `[w,x,y,z]`，Body→NED |
| 欧拉角 | degree；Roll `[-180,180]`，Pitch `[-90,90]`，Yaw `[0,360)` |

ICM的方向事实已经在v0.2.0验收：某机体轴正方向朝上时，该轴约为 `+g`。因此
水平正面朝上时，机体Z正方向朝下，而加速度计静止比力约为 `[0,0,-g]`。
Mahony比较的是“向下重力方向”，故使用：

```text
measured_down_body = -acceleration_body / |acceleration_body|
```

不得把原始比力直接当作向下重力，否则Roll/Pitch反馈方向会反转。

### 3.2 四元数运动学

四元数表示Body→NED旋转，机体系角速度为 `ω=[gx,gy,gz]`：

```text
q_dot = 0.5 * q ⊗ [0, ω]
q_next = normalize(q + q_dot * dt)
```

估计的NED向下轴在机体系中的方向：

```text
estimated_down = [
  2(xz - wy),
  2(wx + yz),
  w² - x² - y² + z²
]
```

Mahony误差使用：

```text
error = measured_down × estimated_down
corrected_rate = gyro + Kp * error + integral_feedback
```

该叉乘顺序已由正Roll、正Pitch测试向量固定，不允许在App侧补符号。

### 3.3 欧拉角和MSP

内部从Body→NED四元数提取：

```text
roll  = atan2(2(wx + yz), 1 - 2(x² + y²))
pitch = asin(clamp(2(wy - zx), -1, 1))
yaw   = atan2(2(wz + xy), 1 - 2(y² + z²))
```

Yaw归一化到 `[0,360)`。标准 `MSP_ATTITUDE` 固定6字节、小端：

| 偏移 | 字段 | 类型 | 单位 |
|---:|---|---|---|
| 0 | Roll | `int16_t` | 0.1° |
| 2 | Pitch | `int16_t` | 0.1° |
| 4 | Heading/Yaw | `int16_t` | 1°，0～359 |

姿态无效时三个字段全部返回0，不能继续发送陈旧姿态。

## 4. Mahony纯C核心

### 4.1 固定参数

| 参数 | 首版值 | 目的 |
|---|---:|---|
| `Kp` | 2.0 | 重力方向比例恢复 |
| `Ki` | 0.05 | 缓慢抑制残余静态角速度偏差 |
| 单轴积分限幅 | 0.25 rad/s | 防止积分失控 |
| 积分允许最大转速 | 20 deg/s | 快速动作时不学习错误偏差 |
| Accel可信范围 | 0.8～1.2 g | 明显线加速度时只作陀螺积分 |
| `dt`可信范围 | 0.5～2.0 ms | 与S3.5输入边界一致 |

首个可信样本由重力直接播种Roll/Pitch，Yaw置0；这样校准完成或故障恢复后不需要
从单位四元数缓慢收敛。加速度模长超界但Gyro和 `dt` 仍有效时保持READY并执行
gyro-only更新，同时累计拒绝计数。

### 4.2 重置规则

下列任一条件发生时，本次不积分，姿态变为无效并重置为单位四元数：

- IMU离线、读取失败或DRDY本周期无新样本。
- Gyro或Accel校准未READY。
- S3.5时间无效或滤波未READY。
- Gyro/Accel向量含NaN/Inf。
- `dt` 非有限或超出0.5～2.0 ms。
- 四元数归一化或欧拉角结果非有限。

输入恢复后必须由新的可信加速度样本重新播种；不能用夹紧后的异常 `dt` 或陈旧
滤波值继续积分。

## 5. 状态、安全和诊断

### 5.1 `app_state`

新增独立姿态快照：

- `valid`
- `quaternion[4]`
- `roll_deg/pitch_deg/yaw_deg`
- `update_count`
- `reset_count`
- `invalid_input_count`
- `accel_rejection_count`
- `gyro_only_update_count`

新增 `APP_ARMING_INHIBIT_ATTITUDE_NOT_READY`。IMU、时间、滤波或校准失效时，
`app_state_publish_imu()` 原子撤销姿态有效性；只有发布READY姿态后才清除此位。

### 5.2 GETFUN MSP2 `0x4002`

固定52字节、小端：

| 偏移 | 字段 | 长度 |
|---:|---|---:|
| 0 | version=1 | 1 |
| 1 | flags，bit0=ATTITUDE_READY | 1 |
| 2 | reserved | 2 |
| 4 | update_count | 4 |
| 8 | reset_count | 4 |
| 12 | invalid_input_count | 4 |
| 16 | accel_rejection_count | 4 |
| 20 | gyro_only_update_count | 4 |
| 24 | quaternion `[w,x,y,z]`，每项 `int32 × 1e9` | 16 |
| 40 | Roll/Pitch/Yaw，每项 `int32` 毫度 | 12 |

### 5.3 UART摘要

1 Hz新增：

```text
att ready=1 updates=... reset=... invalid=... accel_reject=... gyro_only=...
att q_milli=[w,x,y,z] rpy_mdeg=[roll,pitch,yaw]
```

ImuTask和ISR仍禁止直接输出日志。

## 6. 离线测试向量

`Tools/verify_attitude_estimator.mjs` 必须覆盖：

- 水平、+30° Roll、+20° Pitch和组合倾角的重力播种。
- 绕X/Y/Z正方向恒速运动，验证45° Roll、30° Pitch、90° Yaw符号。
- Accel超界时保持READY、计数并进行gyro-only积分。
- 扰动后回到水平，Roll/Pitch在规定时间内恢复。
- 静态Gyro残余偏差被反馈抑制，积分不越界。
- 200,000次更新后四元数模保持1且欧拉角有限。
- 超界 `dt` 立即重置，下一可信样本确定性重新播种。

ARM Debug/Release构建负责覆盖C实现、链接和目标FPU ABI；脚本提供独立数学参考。
