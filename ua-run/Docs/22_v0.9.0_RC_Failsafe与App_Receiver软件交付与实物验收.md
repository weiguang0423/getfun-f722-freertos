# v0.9.0 RC Failsafe与App Receiver软件交付与实物验收

> 合并目标标签：`v0.9.0-flight-input-baseline`（最终以文档24为总关口）  
> 当前结论：2026-08-08开发者确认真实硬件和Betaflight App验收通过

## 1. 软件交付摘要

- 新增纯C `rc_input`映射与Failsafe状态机。
- 保留S3.7 CRSF原始线序，新增AETR到App Roll/Pitch/Yaw/Throttle顺序的映射快照。
- 300 ms通道超时，100 ms加至少5帧的启动/断链恢复门限。
- RC无效时发布 `APP_ARMING_INHIBIT_RC_NOT_READY`，同时在 `MSP_STATUS_EX`投影为 `RXLOSS`。
- 补齐Betaflight App 2025.12.2 Receiver页面的8条标准MSP只读依赖。
- `MSP_RC` 在RC有效时返回16路映射微秒值，无效时返回中立/低油门安全值。
- 新增GETFUN MSP2 `0x4003` 64字节RC/Failsafe诊断。
- UART4 1 Hz新增Failsafe phase、次数、恢复帧数、映射RPYT和解锁抑制摘要。

## 4. 烧录前安全条件

1. 拆除全部螺旋桨。
2. 断开Motor动力电源，只保留飞控、CR8、UART4、USB和SWD所需供电。
3. 使用Debug镜像，保留完整UART4 1 Hz摘要。
4. Betaflight App固定使用 `2025.12.2`，连接后先确认API 1.48和板卡身份。
5. 验收过程不点击Receiver页面Save；S3.8的RX配置响应是只读投影。

## 5. 实物验收

### 5.1 Receiver页面初始化

- [x] Betaflight App Receiver页面可正常打开，不再因必需MSP响应缺失而中断。
- [x] Receiver Mode显示Serial RX，Serial Receiver Provider显示CRSF。
- [x] Channel Map显示 `AETR1234`。
- [x] 页面生成16个通道条，而不是0或默认8路占位。

### 5.2 通道顺序与数值

- [x] Roll摇杆只主要改变App Roll。
- [x] Pitch摇杆只主要改变App Pitch。
- [x] Yaw摇杆只主要改变App Yaw。
- [x] Throttle摇杆只主要改变App Throttle。
- [x] AUX1～AUX12与发射机开关逐一对应。
- [x] 中位约1500 us，常规端点约1000/2000 us，App与UART `app_rpyt`一致。

### 5.3 启动恢复门限

- [x] 未建链时UART显示 `valid=0 failsafe=1 phase=0`，且解锁抑制含bit 6。
- [x] 首次收到帧后先进入 `phase=1`，不在单帧后立即撤销Failsafe。
- [x] 持续建链至少100 ms且收到至少5帧后，转为 `valid=1 failsafe=0 phase=2`。
- [x] 恢复后 `MSP_STATUS_EX` 中的 `RXLOSS` 消失。

### 5.4 断链Failsafe

- [x] 关闭发射机或断开RF链路，最后通道帧后299 ms前不误触发。
- [x] 300 ms阈值到达后进入 `valid=0 failsafe=1 phase=3`，`failsafe_count`增加一次。
- [x] App的Roll/Pitch/Yaw回到1500，Throttle和AUX回到1000。
- [x] App顶部解锁拒绝原因可见 `RXLOSS`。
- [x] 断链期间Motor GPIO持续保持安全低电平。

### 5.5 恢复与抖动拒绝

- [x] 恢复RF后先进入 `phase=1`，100 ms/5帧前 `valid`仍为0。
- [x] 只恢复1～4帧后再断开，不会短暂进入 `HEALTHY`。
- [x] 连续恢复达标后 `recovery_count`增加，通道和Link Statistics继续更新。
- [x] 本阶段不宣称实现“恢复后必须重新拨ARM”；该锁存属于后续ARM状态机。

### 5.6 长时稳定性与回归

- [x] Receiver页面持续打开30分钟，通道更新连续，USB无掉线或MSP错误风暴。
- [x] `rc stack_min`保持不低于128 words。
- [x] CRSF CRC/长度/Payload错误、DMA overflow和UART recover无异常持续增长。
- [x] IMU约1 kHz、Mahony姿态、App三维模型和参数A/B槽无回退。
- [x] Debug/Release最终构建和五组离线回归全部通过。
