```text

  -> S4.4端点/Deadband/Actual Rates
```

## 3. S4.5 Rate PID契约

内部setpoint和测量值统一为rad/s，`dt`统一为second。FlightTask只在
`imu.sample_count`变化时更新一次控制器，直接使用已经通过S3.5门禁的
`sample_interval_us`；允许范围为500～2000 us。

每轴公式：

```text
error = setpoint - measurement
P = Kp * error
I_candidate = clamp(I + Ki * error * dt, -I_limit, +I_limit)
D_raw = -Kd * (measurement - previous_measurement) / dt
D = PT1_150Hz(PT1_75Hz(D_raw))
output = clamp(P + I + D, -output_limit, +output_limit)
```

默认只读初值不是飞行调参结论：

| 轴 | Kp | Ki | Kd |
|---|---:|---:|---:|
| Roll | 0.10 | 0.25 | 0.001 |
| Pitch | 0.10 | 0.25 | 0.001 |
| Yaw | 0.12 | 0.25 | 0.000 |

公共限制：`I_limit=0.20`，`output_limit=0.50`。D项只对测量值求导并经过75/150 Hz两级PT1，摇杆setpoint跳变
不会直接生成D kick。输出已经饱和且误差仍把同方向推向饱和时，拒绝本次积分增长。

当前尚无S4.7真实ARM状态，因此只把S4.4的AUX1 ARM请求作为“诊断积分允许”条件：
AUX1请求有效且Throttle大于5%时允许积分；低油门、AUX1退出、任一安全门禁、ANGLE请求、
异常dt或NaN/Inf都会清零积分。该条件不代表已ARM，也不授权电机输出。

## 4. S4.6 Quad-X契约

首版采用本地Betaflight源码`mixerQuadX`的标准逻辑顺序：

| 逻辑电机 | 标准位置 | Roll | Pitch | Yaw |
|---|---|---:|---:|---:|
| M1 | Rear Right | -1 | +1 | -1 |
| M2 | Front Right | -1 | -1 | +1 |
| M3 | Rear Left | +1 | +1 | +1 |
| M4 | Front Left | +1 | -1 | -1 |

文档26只记录M1～M4实体位置/方向“已核对”，没有补录具体位置，因此文档30必须再次确认
实际机架位置与本表一致；若不一致，应修正唯一矩阵或补录映射，不能随机交换电机掩盖符号问题。

饱和策略：

1. 先计算四路Roll/Pitch/Yaw修正值。
2. 如果最大值与最小值之差大于1，统一缩放全部修正，使差值等于1。
3. 在不改变四路相对差值的前提下平移Throttle，使全部结果落在`[0,1]`。
4. 最后仅作浮点边界裁剪，禁止整数回绕。

## 5. FlightTask、状态和诊断

FlightTask静态栈由384增加到512 words，用于容纳扩展后的完整状态快照和控制诊断。
控制更新同时要求：IMU/滤波/姿态新鲜、RC有效且未Failsafe、全部既有inhibit为0、
S4.4 setpoint有效且当前为RATE模式。没有新IMU样本时保持上次诊断，不重复积分或求导。

新增GETFUN MSP2 `0x4008`只读106字节状态，包含：

- PID/Mixer有效、饱和和积分门禁标志。
- 控制样本号、真实dt、更新/错误计数。
- 默认Kp/Ki/Kd、积分和输出限制。
- 三轴setpoint、测量、误差、P/I/D和最终修正。
- Mixer请求/应用Throttle、修正缩放系数和M1～M4逻辑值。

UART4每秒新增`control`、`pid_terms`和`mixer`摘要。所有运行态来自同一`app_state.flight`快照，
MSP层不持有第二份PID或Mixer状态。
