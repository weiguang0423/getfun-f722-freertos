# v1.4.0 S4.8/S4.9拆桨阶段收尾开发计划

## 1. 实现来源与边界

| 范围 | 策略 | 固定来源 | 项目适配 |
|---|---|---|---|
| Angle外环 | 参考成熟实现后复现 | Betaflight官方`flight/pid.c`：目标倾角、角度误差、Angle gain和Rate内环结构 | 只复现公式；使用本项目FRD/NED姿态、RC归一化、Rate PID和安全状态机，不复制GPL源码 |
| App页面协议 | 官方协议直接适配 | Betaflight官方MSP API 1.48及Betaflight App 2025.12.2提交`a2d0f506` | 按页面真实请求实现最小标准MSP投影；不支持的硬件项只允许原值回写 |
| 参数事务 | 完全自主实现 | 既有Sector 6/7 A/B槽、CRC32和commit-last安全契约 | v2记录保留v1加速度校准迁移；Flash仍只由ImuTask在DISARMED状态写入 |

不引入新依赖、动态内存、Horizon、Angle feedforward、地球坐标Yaw补偿、双向DShot、RPM
Filter或新的传感器/电机协议。上述能力不属于S5前拆桨出口。

## 2. S4.8 Angle外环

Roll/Pitch使用：

```text
target_angle_deg = normalized_stick * angle_limit_deg
error_angle_deg = target_angle_deg - measured_angle_deg
target_rate_dps = clamp(error_angle_deg * angle_p, ±angle_rate_limit_dps)
```

Yaw继续使用S4.4 Actual Rates输出。默认`angle_limit=60 deg`、`angle_p=5.0 s^-1`、
`angle_rate_limit=670 deg/s`；只接受有限值和有界Profile。姿态、RC或计算无效时整条控制
输出立即失效，沿用S4.7 `CONTROL_INVALID`停机路径。ANGLE和RATE切换时复位Rate PID状态，
避免旧积分或D项历史跨模式保留。

验收向量：摇杆回中且机体正Roll/Pitch时目标Rate必须为负；满杆目标倾角不得超过60°；
Yaw设定与Rate模式一致；AUX2进入ANGLE后不再触发S4.7临时block。

## 3. S4.9持久参数

参数记录升级为v2，并兼容读取既有48字节v1记录。v1加载后保留加速度偏置并为新增字段
填充安全默认值；下一次成功保存才写入v2，不原地改写活动槽。

持久化项目：

- RC端点、10 us Deadband、Actual Rates/Expo；
- AUX1 ARM和AUX2 ANGLE通道及范围；
- 三轴Rate PID Kp/Ki/Kd；
- Angle P、最大倾角和外环Rate上限；
- DShot `motor_idle`；
- Craft/Pilot名称。

MSP SET命令只修改MspTask私有暂存副本；`MSP_EEPROM_WRITE`才把完整事务交给ImuTask。
事务1秒无后续命令即失效。SET、EEPROM和非零Motor Test均拒绝ARMED；ImuTask在实际擦写
前再次检查ARMED，避免请求与解锁竞态。保存成功后一次性发布新Profile，失败或超时不改变
FlightTask正在使用的配置。

## 4. Betaflight App 2025.12.2页面契约

| 页面 | 可读写并持久化 | 只读/原值回写 | 运行时命令 |
|---|---|---|---|
| PID Tuning | Roll/Pitch/Yaw PID、Actual Rates/Expo、Angle P/Limit | Filter、Simplified Tuning、Mixer和未实现高级PID字段 | `MSP_EEPROM_WRITE` |
| Modes | ARM、ANGLE两个mode range | AND逻辑、无linked mode、USART2 CRSF串口事实 | 逐slot `MSP_SET_MODE_RANGE` |
| Motors | `motor_idle` | DShot600、Quad-X、非3D、无遥测、固定输出顺序 | 标准`MSP_SET_MOTOR`映射到既有250 ms测试门禁 |
| Configuration | Deadband、Craft/Pilot名称 | RX/CRSF、板级对齐、传感器和ARM固定安全项 | `MSP_EEPROM_WRITE` |

任何尝试改变只读硬件事实的SET负载返回MSP错误，不静默保存。Motor页面非零输出还必须满足
Configurator已禁止解锁、RC ARM低位、输入新鲜、DShot健康和DISARMED；1000映射停止，
1001～2000线性映射到DShot 48～2047，仍由250 ms未刷新归零。
