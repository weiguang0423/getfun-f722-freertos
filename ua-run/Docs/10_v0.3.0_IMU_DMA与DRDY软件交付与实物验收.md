# v0.3.0 IMU DMA与DRDY软件交付及实物验收

> 上一基线：`v0.2.0-imu-polling-baseline`（`4452a28`）  
> 目标标签：`v0.3.0-imu-dma-drdy-baseline`  
> 软件完成日期：2026-07-27  
> 当前状态：开发者已于2026-07-27确认发布，并授权创建目标标签

## 1. 交付结论

本轮已把稳定运行时的ICM42688P 14字节样本读取从阻塞SPI改为SPI1全双工DMA。
传感器初始化、寄存器配置和DRDY状态查询继续使用短阻塞事务，降低启动和恢复路径的
复杂度。

本版中的“DRDY”含义是：

```text
1 kHz vTaskDelayUntil
  → 读取 INT_STATUS.DATA_RDY_INT
  → ready时启动SPI1 DMA样本事务
```

原始GETFUNF722V3目标没有定义IMU INT外部引脚，PC4已属于PINIO1，因此本版没有
配置GPIO EXTI，也不能写成“外部DRDY中断已经实现”。

## 2. 已交付的软件内容

### 2.1 CubeMX与HAL

- SPI1 RX：DMA2 Stream 0 / Channel 3。
- SPI1 TX：DMA2 Stream 3 / Channel 3。
- 数据宽度：Byte；内存递增；Normal模式；High优先级；FIFO关闭。
- 两个DMA IRQ抢占优先级均为5，可安全调用FreeRTOS `...FromISR()` API。
- `MX_DMA_Init()`在GPIO之后、SPI1之前执行。
- SPI MSP初始化链接 `hspi1.hdmarx` 和 `hspi1.hdmatx`。
- SPI、DMA、MSP、IRQ和初始化调用均由`.ioc`生成；APP不直接维护DMA句柄。
- 调度器异常返回的项目安全停机调用位于`USER CODE BEGIN WHILE`保护块。
- 生成文件的项目说明位于`USER CODE BEGIN Header`保护块。

### 2.2 总线与器件驱动

- 两个静态DMA槽位，每个包含64字节TX和64字节RX缓冲。
- 槽位整体按32字节对齐并交替使用。
- `start()`、完成、错误和`abort()`路径均恢复PA4 CS高电平。
- DMA前后包含条件式D-Cache clean/invalidate；当前固件仍只启用I-Cache。
- ICM42688P器件层继续负责14字节大端解析，任务层不解释寄存器字节。
- 初始化、WHO_AM_I、配置写入/回读和DRDY查询保留阻塞接口。

### 2.3 ImuTask与状态

- ImuTask继续使用静态512 words栈和`tskIDLE_PRIORITY + 4`。
- 每周期先查询 `INT_STATUS.DATA_RDY_INT`，未就绪不启动DMA。
- DMA ISR只关闭CS、保存完成状态并用直接任务通知唤醒ImuTask。
- DMA等待上限2 ms，超时后执行HAL SPI abort。
- 连续三次读失败后IMU离线并进入现有完整重初始化流程。
- app_state新增DRDY轮询、DMA成功、启动错误、完成错误、超时和abort累计计数。
- SI单位、`CW90_DEG`轴变换和MSP缩放没有改变。

## 4. UART预期输出

启动阶段应出现：

```text
IMU: SPI1 1687500 Hz mode=0 dma2 rx=s0 tx=s3 trigger=drdy_poll
```

运行阶段每秒应出现三类IMU摘要：

```text
imu present=1 who=0x47 status=0 bus=0 hz=... samples=...
imu dma_ok=... drdy_poll=... dma_start_err=0 dma_cplt_err=0 dma_timeout=0 dma_abort=0
imu acc_mm_s2=[...] gyro_mrad_s=[...] temp_mc=... imu_stack_min=...
```

正常连续运行时：

- `dma_ok`应与`samples`同步增长。
- `drdy_poll`约每秒增加1000。
- `hz`应稳定在990～1010。
- `not_ready`允许偶发增加；它表示查询时新样本尚未就绪，不等同于SPI错误。
- 四个DMA错误计数和`dma_abort`不应持续增长。

## 5. 状态码速查

`status`（ICM42688P）：

| 值 | 含义 |
|---:|---|
| 0 | 正常 |
| 1 | 参数错误 |
| 2 | 总线错误 |
| 3 | WHO_AM_I不匹配 |
| 4 | 配置回读不匹配 |

`bus`（imu_bus）：

| 值 | 含义 |
|---:|---|
| 0 | 正常 |
| 1 | 参数错误 |
| 2 | SPI/DMA未准备 |
| 3 | HAL错误 |
| 4 | HAL忙或存在未消费DMA结果 |
| 5 | HAL超时 |
| 6 | DMA尚未完成 |
| 7 | DMA已被终止 |

- [ ] PA4在完整15字节事务期间保持低电平。

### 6.4 故障恢复和稳定性

- [ ] 可控制造SPI/DMA失败后，CS能够恢复高电平。
