# RK3568 Linux 开发入口

本目录是RK3568侧的Git原件。Windows保存仓库，WSL负责模型转换和ARM64交叉构建，RK3568只
保存部署副本并运行程序；WSL和开发板中不得保留未归档的唯一源码或验收结论。

## 目录

- `s7_1_rknn_smoke.c`：S7.1最小RKNN Runtime/NPU冒烟程序。
- `s7_2/`：TFLite PC参考链、最小自检和三次冻结结果。
- `s7_3/`：RKNN转换、ARM64板端程序、交叉构建、误差比较和S7.3验收摘要。
- `s7_4/`：复用FP16推理的V4L2实时入口、交叉构建、5分钟资源观测脚本和实物摘要。

## 文件边界

Git提交源码、脚本、测试、版本/哈希清单和验收摘要。RK3568 SDK、Python虚拟环境、OpenCV构建
目录、`.rknn`、ARM64可执行文件、测试语料和一次性部署包均为外部依赖或可重建产物，不进入普通
Git提交；正式交付时应作为同一Git标签对应的Release附件归档，并用SHA-256绑定。

当前冻结环境和外部产物位置见`s7_3/evidence/host_preparation.json`。这些绝对路径是本次验收
记录，不是项目接口；构建脚本可通过`SDK`、`BUILD`和`OPENCV`环境变量改用其他位置。
